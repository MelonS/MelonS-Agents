## 핵심 기술 발견

- **libass PlayResY 스케일 버그** (`3decfa7`): SRT를 ASS로 변환 시
  libass가 default PlayResY=288에 대해 Fontsize 해석. 1920px 출력에
  서 6.67배 폰트 부풀음. 해결: `ass=` 필터 + PlayResY=1920 명시한
  .ass 사이드카 직접 생성.
- **bash 3.2 호환성** (`123f895`): macOS 기본 bash가 여전히 3.2라
  `declare -A` 못 씀. `case` 디스패치로 우회.
- **Process-sub 내부 heredoc stdin 충돌**: `< <(python3 - <<'PY' ...)`
  형식이 macOS bash에서 ambiguous redirect 에러. 변수에 캡처 후
  `<<<` 사용으로 우회. (`fetch-fixtures.sh`, `pexels-fetch.sh` 양쪽)
