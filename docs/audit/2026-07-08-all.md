- **[medium]** Precomputed skill-drift finding (job-hunt, "manifest
  references missing script") is a parsing artifact of CRLF contamination
  in the manifest, not an actual missing file — root cause also explains
  the already-tracked status.sh CRLF crash — `skills/job-hunt/config/activation.tsv`,
  `.gitattributes` (no *.tsv rule), `scripts/audit-skill-drift.sh` lines
  74-92, `skills/job-hunt/scripts/status.sh`.
  Evidence: inspecting the raw bytes of `skills/job-hunt/config/activation.tsv`
  shows CRLF line endings throughout, including two blank separator lines
  that are literally the single carriage-return byte, not a truly empty
  line. `scripts/audit-skill-drift.sh`'s blank-line skip test does not
  fire for these lines because the flag variable holds that one
  carriage-return character rather than an empty string, so the line
  proceeds to build a script path from an empty path field, producing
  the skill directory itself (not a file), which fails the file-exists
  test and emits the empty-subject finding seen in this cycle precomputed
  report (manifest references missing script, with the description field
  blank, confirmed by running the script in JSON mode). All 16 actually
  declared scripts in the manifest exist and are present on disk; nothing
  is really missing. Separately, `skills/job-hunt/scripts/status.sh` was
  run directly this cycle and still crashes (exit code 3, malformed
  manifest row with an empty value), the exact same CRLF blank-line
  defect, independently confirming the current alert's 6th-consecutive-
  cycle-unresolved claim. Checking git attributes confirms an eol=lf rule
  exists for *.sh (which is why status.sh's shebang line itself is
  unaffected, CRLF survives there only because the file predates the
  rule and was never renormalized) but there is no rule at all for *.tsv,
  falling back to the generic text=auto default, which does not force LF.
  Suggested fix: add a *.tsv eol=lf rule to `.gitattributes`, then
  renormalize `skills/job-hunt/config/activation.tsv` and
  `skills/job-hunt/scripts/status.sh` and commit; also harden the
  blank-line skip logic in both `scripts/audit-skill-drift.sh` and
  `status.sh` to strip a trailing carriage return before the emptiness
  test, so a future CRLF regression degrades gracefully instead of
  misreporting.
