- **[medium]** Skill-activation drift report row is a false positive — root cause is a parsing bug in `scripts/audit-skill-drift.sh`, not `skills/job-hunt`
  Evidence: the precomputed report flags "job-hunt: manifest references
  missing script" with an empty subject field. Manual verification
  (awk field-count over `skills/job-hunt/config/activation.tsv`)
  shows every declared flag-to-script pair in the manifest resolves to a
  file that exists; the two rows the script actually chokes on are the
  blank separator lines (21 and 37). `file skills/job-hunt/config/
  activation.tsv` reports CRLF line terminators on this Windows checkout
  even though `git show HEAD:skills/job-hunt/config/activation.tsv`
  is pure LF — a local checkout-only artifact. Because
  `audit-skill-drift.sh`s read loop only skips a line when `$flag` is
  exactly empty (`[[ -z "${flag:-}" ]]`), a blank line whose only content
  survives as a lone CR character (no tab to split on) lands entirely in
  `$flag`, fails the emptiness test, and produces a bogus "missing
  script" finding against an empty path (a directory, not a file). The
  `job-hunt` manifest itself has zero real drift.
  Suggested fix: harden `scripts/audit-skill-drift.sh`s manifest read
  loop to strip a trailing CR and skip lines where `$flag` is empty or
  whitespace-only after trimming, so the script is robust to CRLF
  checkouts.
