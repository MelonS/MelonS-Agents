  Evidence: `.claude/agents/planner.md:5` shows `model: opus`; `.claude/agents/resourcer.md:5` shows `model: opus`.  The table at `docs/for-analysts.md:100-101` lists both as `sonnet`.  The three-commit A/B arc (commits `fcc5fee`, `f714a5848`, `2778316`) ended with commit `2778316` ("config(agents): planner + resourcer → opus (multi-week production trial)", 2026-05-22) re-assigning both to opus.  That commit's message explicitly states "README EN + KO architecture diagram + subagent table + cost-model estimate column updated" but `docs/for-analysts.md` was not in the diff.  Additionally: (a) `docs/for-analysts.md:94-95` claims the last commit to `.claude/agents/*.md` was `8570a9c` but `git log -- '.claude/agents/*.md'` shows `2778316` as the most recent; (b) `docs/for-analysts.md:106-107` says "A common analyst suggestion is 'downgrade subagents from opus to sonnet.' This is already done" — this statement is now factually reversed.
  Suggested fix: Update `docs/for-analysts.md` table rows for `planner` and `resourcer` to `opus`, correct the last-commit hash to `2778316` and date to 2026-05-22, and rewrite the "already done" downgrade note to reflect the current opus assignment rationale.

Commit modifies both `planner.md` and `resourcer.md` (§5-scope files), is dated 2026-05-22 (post-convention), and is reachable from `origin/main`.  No `Requested-by: user` footer.
