## Findings

- **[low, carry-forward]** §12 — LinkedIn URL with real-name path component
  committed — `site/index.html:169`
  Evidence: `site/index.html:169` contains
  `<a href="https://www.linkedin.com/in/eun-hyung-choi" ...>LinkedIn</a>`.
  The URL path component `eun-hyung-choi` encodes a real-name identifier
  in a file committed to the public repo.  `Requested-by: user` is present in
  commit `75b10a8` documenting operator intent, but §12 defines no formal
  override mechanism for PII on intentionally public surfaces.  Risk is low
  (professional-networking URL, publicly visible); unchanged across three prior
  audits.
  Suggested fix: Amend `docs/operator-contract.md §12` to add an explicit
  operator-override clause for identity information on intentionally public
  surfaces, then add a `<!-- §12 operator-authorized deviation -->` comment
  beside the anchor in `site/index.html:169`.

- **[low, carry-forward]** §8 — Four launchd plist files hardcode
  `/Users/melons/...` absolute paths; migration comment is inaccurate —
  `scripts/com.melons.agents.auditor.plist:15,20,23,26,53`,
  `scripts/com.melons.agents.audit-poll.plist:15,19,22,25,46`,
  `scripts/com.melons.agents.disk-watch.plist:15,19,22,25`,
  `scripts/com.melons.agents.queue.plist:15,19,22,25`
  Evidence: launchd does not expand shell variables in plist XML values;
  absolute paths are structurally required.  All four plists carry an inline
  `<!-- §8 exception: launchd plist values do not expand shell variables … When
  the repo is relocated, re-run scripts/install-scheduler.sh on the new machine
  to regenerate the LaunchAgents copy. -->` comment.  However,
  `scripts/install-scheduler.sh` performs a plain `cp "$src" "$dst"` (line 59)
  — it does NOT regenerate the paths; on a machine swap the hardcoded
  `/Users/melons/` paths will be wrong even after re-running the installer.
  Unchanged across ten prior audits.
  Suggested fix: Generate all four plists from `*.plist.template` sources via
  `sed "s|@@REPO@@|$(pwd)|g; s|@@HOME@@|$HOME|g"` at install time inside
  `scripts/install-scheduler.sh`; commit only the `.plist.template` files;
  add the rendered `*.plist` files to `.gitignore`.
