# 한국어 README 스타일 가이드 · EN↔KO 유지 규칙

`README.ko.md` 는 `README.md` 를 손으로 미러링하는 문서라, 손댈 때마다 두 방향으로 품질이 샌다.

1. **구조·수치 드리프트** — 섹션 하나 누락, 숫자(24 → 19)가 EN 과 어긋남, 링크 하나 빠짐.
2. **직역 계(calque)** — 영어 단어를 그대로 옮겨 한국어로는 어색한 표현("출하", "들어오는 길에", "핸드오프").

이 문서는 그 재발을 막기 위한 **작업 규칙 + 용어집**이다. 구조 드리프트는 스크립트가, 번역 품질은 사람/LLM 이 잡는다 — 아래 "검증 절차" 참고.

---

## 1. 문체 규칙

- **합니다체로 일관.** 문어체 기술 문서 톤을 유지한다. 구어체 조사(`~한테`, `~거든요`)나 반말("누구나 한다")을 문어체와 섞지 않는다. → `~에게`, "누구나 합니다".
- **영어식 대시(—) 남발 금지.** 원문의 `— … —` 삽입구를 그대로 옮기면 한국어 호흡이 끊긴다. 쉼표·괄호·콜론으로 풀거나 문장을 나눈다.
  - ✗ `각 클릭이 효과를 냈는지 — 예컨대 "…" — 어서트합니다.`
  - ✓ `각 클릭이 효과를 냈는지, 가령 "…"를 어서트합니다.`
- **마침표 뒤 한 칸.** 영어 원문의 "마침표 + 두 칸"을 그대로 옮기지 않는다(볼드 리드인 `**…**  텍스트`의 두 칸은 EN 과 맞춘 스타일이므로 예외).
- **의미를 옮기고, 단어를 옮기지 않는다.** 직역해서 어색하면 같은 뜻의 자연스러운 한국어로 다시 쓴다.
- **그대로 두는 것:** 제품명(`music-video`, `job-hunt`, `PawnSim`, `game-dev-agent`), 도구명(`ffmpeg`, `ollama`, `whisper.cpp`, `aubio`), 코드/경로/플래그, 그리고 이 문서에서 **정의한 용어**(소크/soak, 재현 게이트, 격리 채점, 어서트).
- **외래어 표기 일관.** 이 저장소는 `쉐이더/쉐이딩`(쉐-)으로 통일한다. `셰-`와 섞지 않는다.

## 2. 용어집 — 이 계(calque)들은 다시 쓰지 않는다

| 영어 | ✗ 직역(피함) | ✓ 자연스러운 한국어 |
|------|-------------|---------------------|
| ship (outputs) | 출하 | 내놓다 · 만들어 내다 |
| spine (of the repo) | 척추 | 핵심 · 근간 |
| on the way in | 들어오는 길에 | (코드가) 반영되기 전에 |
| jittered clock | 지터를 준 시계 | 불규칙한 주기 |
| mood-gate | 기분 게이트 | 기분(mood) 게이트 *(표기 병기)* |
| emit code | 코드를 뱉다 | 코드를 만들어 내다 |
| paint (designations) | 명령을 칠하다 | 명령을 내리다 · 지정하다 |
| handoff | 핸드오프 | (작업을) 넘겨주다 |
| out-of-band | 비대역 | 본체와 분리돼(out-of-band) 도는 |
| draft (pawns) | 폰을 징발 | 폰을 (전투에) 징집 |
| ledger | 원장 | 정확한 집계 |
| freeze (bug) | 프리즈 | 멈춰 버리는 버그 |
| end-to-end | 엔드투엔드 | 처음부터 끝까지 |
| live alert surface | 라이브 알림 표면 | 실시간 경보창 |
| silent failure | 조용한 실패 *(명사구)* | 조용히 실패해 버리는 일 *(서술)* |
| absorbs prompts | 질문을 흡수한다 | 질문을 대신 받아 준다 |
| round-trip (Suno) | 왕복 | 호출 · 연동 |
| routing / orchestration | 라우팅 | 배정 / 지휘·조율 *(오케스트레이션은 통용, 허용)* |

> 새 계를 발견하면 여기에 한 줄 추가한다 — 이 표가 재발 방지의 실체다.

## 3. 검증 절차 (커밋 전)

**Layer 1 — 구조/수치 패리티 (결정론적, 자동).**
```bash
python scripts/readme-parity.py     # 섹션·이미지·표·코드블록 수 + 링크 집합 + 히어로 숫자 = EN↔KO 일치 검사
```
`main-protection.yml` CI 에도 물려 있어, 드리프트가 있으면 `main` 이 빨개진다. exit 1 이면 EN 에 맞춰 KO 를 고친다.

**Layer 2 — 번역 품질 (사람/LLM, 판단 필요).**
자연스러움과 충실도는 스크립트가 못 잡는다. KO 를 크게 손댔으면, 한국어 원어민 관점(개발자/에디터/이중언어 번역가)으로 (1) 번역투·계가 남았는지 (2) EN 대비 의미 왜곡·누락·추가가 없는지 확인한다. 위 용어집을 체크리스트로 쓴다.

## 4. 패리티가 검사하는 것 / 안 하는 것

- **검사함:** `## ` 섹션 수, 이미지·표 행·코드블록 수, 로컬 링크 집합(`-ko`/`.ko` 변형은 기준형으로 정규화 후 비교), 히어로 스탯 이미지 alt 의 숫자 집합.
- **안 함:** 번역 품질, 문장 자연스러움, 문단 단위 의미 일치. → Layer 2 의 몫.
