# 아트 톤 결정 가이드 — "뭘 정해야 하나" (2026-07-25)

**지위**: `art-style-guide-v3.md`(정본)의 **보강 문서**. v3가 "규격·팔레트·프롬프트"를 정했다면,
이 문서는 그 위에서 **아직 안 정해진 톤 결정 항목**을 비디자이너용 언어로 정리하고,
결정 없이도 파이프라인이 기계적으로 강제할 수 있는 장치를 우선순위로 나열한다.

원리 한 줄: **스타일 일관성 = (사람이 정하는 소수의 규칙) × (파이프라인이 강제하는 자동 통일)**.
생성형 AI는 매 배치가 미묘하게 다르게 나오므로, 규칙은 적게·명확하게 정하고 나머지는 후처리가 눌러준다.

---

## 파트 1 — 운영자가 정할 것 (결정 체크리스트)

각 항목: 쉬운 설명 → 선택지 → **추천 디폴트**(현 반입물 기준). 추천대로 가려면 "OK"만 하면 된다.

### 1-1. 밸류 위계 (명도 계급) — 가장 중요
- **설명**: 화면을 흑백으로 바꿨을 때 "뭐가 먼저 보이는가"의 순서. 탑다운 시뮬 장르의 표준은
  **지형(바닥) 가장 어둡게 → 오브젝트(나무·광맥·가구) 중간 → 캐릭터 가장 밝게**.
  이 순서만 지켜도 오브젝트가 바닥에서 "떠 보이고" 캐릭터가 즉시 눈에 들어온다.
  (MOBA·전략 게임들이 공통으로 쓰는 규칙: 바닥은 유닛보다 어두운 회색조, 바닥 디테일은 명암 대비 최소화.)
- **선택지**:
  - (a) 3계급: 지형 V중심 ~0.40 / 오브젝트 ~0.55 / 캐릭터 ~0.70
  - (b) 2계급: 지형만 어둡게, 오브젝트=캐릭터 동급
  - (c) 위계 없음 (현 상태 — 대상별 명도가 제각각)
- **추천**: **(a)**. 실행은 간단하다 — 지형 타일은 하모나이즈에서 **명도 -10%** 일괄 적용,
  오브젝트는 V 0.20~0.85 클램프, 캐릭터(림)만 V 0.92까지 허용. 숫자는 §2-2 표로 파이프라인화.

### 1-2. 채도 전략 (색 진하기 계급)
- **설명**: 채도(색의 쨍함)도 위계를 준다. **배경·지형은 물 빠진 색, 클릭 가능한 것일수록 진한 색**.
  플레이어 눈은 자동으로 채도 높은 곳에 간다 — "중요한 것 = 진한 색"이 게임 문법.
- **선택지**:
  - (a) 3단: 지형 S≤0.45 / 정적 오브젝트 S≤0.65 / 캐릭터·선택 표시·위험 신호 S≤0.75(포인트 0.85)
  - (b) 2단: 지형 저채도 / 나머지 전부 v3 상한(0.75)
  - (c) 단일 상한만 (현 v3 §2 상태)
- **추천**: **(a)**. v3의 상한 0.75/포인트 0.85와 충돌하지 않고 아래로 세분화만 하는 것.
  단풍(maple)·경고색만 0.85 예외 유지, "화면당 소량" 규칙 그대로.

### 1-3. 계절 고정 (컬러 스크립트의 최소 버전) — 현 반입물의 최대 이슈
- **설명**: 컬러 스크립트란 "장면·지역별 대표색 계획표"다. 우리 규모에서 최소 버전은
  **"이 맵은 무슨 계절인가"를 하나로 정하는 것**. 지금 나무 5종은 계절이 섞여 있다
  (oak=한여름 초록, birch=가을 노랑, maple=단풍 절정) → 같은 화면에 깔면 "계절이 뒤죽박죽"으로 읽힌다.
- **선택지**:
  - (a) **늦여름~초가을 하나로 고정**: 기본 수종은 초록~황록, 단풍은 maple 한 종만 포인트로 허용
  - (b) 바이옴별 계절 (온대=여름, 한대=상록 등) — 지형 타일 세트가 늘어남
  - (c) 시즌 시스템 (계절마다 에셋 4벌) — 지금 규모에선 과투자
- **추천**: **(a)**. birch는 황록 쪽으로 재생성 또는 후처리 색상 시프트. maple의 "화면당 소량" 규칙이
  자연히 지켜지도록 스폰 비율도 낮게. 시간대(아침/밤) 톤은 에셋이 아니라 §1-6 런타임 틴트로 해결.

### 1-4. 아웃라인 정책
- **설명**: 스프라이트 가장자리에 어두운 선을 두를지. 선이 있으면 어떤 바닥 위에서도 또렷하지만
  전부 두르면 스티커 느낌. 표준 선택지는 "전부 / 선택적 / 없음"이며 **카테고리별로 다르게** 가는 게 요령.
- **선택지**:
  - (a) 인터랙티브 오브젝트·캐릭터 = 은은한 다크 아웃라인(순흑 금지, 인접색의 어두운 버전) / 지형 = 없음
  - (b) 전부 아웃라인
  - (c) 전부 없음 (명도 위계에만 의존)
- **추천**: **(a)** — v3의 "은은한 다크 아웃라인"을 카테고리 규칙으로 명문화.
  현 반입물은 나무=아웃라인 있음 / 바위=없음으로 이미 갈라져 있어(파트 3 참고) 이 결정이 필요하다.
  바위·광맥도 인터랙티브(채굴 대상)이므로 은은한 외곽선을 후처리로 추가하는 쪽.

### 1-5. 광택 정도 (무광 vs 유광)
- **설명**: 하이라이트가 반짝이면 "캔디/모바일 캐주얼" 결, 무광이면 "미니어처/보드게임 말" 결.
  둘 다 정답이지만 **섞이면 다른 게임 두 개**처럼 보인다. 현재 나무 일부는 유광, 바위는 무광.
- **선택지**: (a) 무광 페인털리(하이라이트 억제) / (b) 은은한 광 허용 / (c) 유광 통일
- **추천**: **(a) 무광**. v3의 "detailed miniature illustration" 컨셉과 정합하고, 바위 반입물이 이미
  무광이라 나무 쪽을 맞추는 게 싸다. 프롬프트 금지어에 `glossy, shiny, candy` 추가(§2-1).

### 1-6. 시간대·날씨 톤의 소유권
- **설명**: 아침/노을/밤 분위기를 에셋에 굽지 말고 **엔진의 전역 컬러 틴트(그레이딩)**로 처리할지 결정.
  에셋에 구우면 시간대별로 전 에셋을 다시 만들어야 한다.
- **선택지**: (a) 에셋=중립광 고정 + 런타임 틴트 / (b) 시간대별 에셋
- **추천**: **(a)**. v3의 "좌상광 고정"이 이미 중립광 전제다. 이 항목은 "결정만 기록"하면 되는 공짜 항목.

### 1-7. 셰이프 랭귀지 (실루엣 규칙)
- **설명**: 카테고리마다 "형태의 성격"을 한 줄로 정해두면 신규 에셋 큐레이션 때 흔들리지 않는다.
  둥근 형태=유기·안전, 각진 형태=광물·위험 이 게임 문법의 기본.
- **추천 디폴트** (현 반입물이 이미 이 방향):
  - 식생 = 둥근 유기 덩어리 (클러스터 3~7개로 읽힘)
  - 광물·바위 = 각진 파셋(면), 직선 모서리
  - 인공물(가구·건물) = 직선 + 모서리만 살짝 둥글게
  - 캐릭터 = 단순 둥근 실루엣, 1x 크기에서 머리/몸 2덩어리로 식별
- **선택지랄 것 없이 "이대로 채택 여부"만 결정.**

### 1-8. 디테일 밀도 (카메라 거리 대비)
- **설명**: 64px 셀 기준 화면에서 스프라이트는 손톱만 하다. 디테일이 많을수록 축소 시 노이즈가 된다.
  규칙: **"실제 게임 배율(1x)에서 큰 덩어리 3~7개로 읽히면 합격, 그 이상 잔디테일은 감점"**.
  v3 큐레이션 5번(실루엣 식별)의 정량 버전. 픽셀 밀도(64px/셀)를 에셋 간에 섞지 않는 것도 이 항목.
- **선택지**: (a) 3~7덩어리 규칙 채택 / (b) 현행 정성 판단 유지
- **추천**: **(a)** — 큐레이션 체크리스트에 한 줄 추가만 하면 됨.

> **우선 결정 톱5**: 1-1 밸류 위계 → 1-3 계절 고정 → 1-5 무광 통일 → 1-2 채도 3단 → 1-4 아웃라인 정책.
> 나머지(1-6~1-8)는 추천 디폴트 승인만으로 충분.

## 파트 2 — 파이프라인이 강제할 것 (자동 통일 장치, 적용 쉬운 순)

사람이 매번 눈으로 맞추는 대신 기계가 눌러주는 층. 위에서부터 즉시 적용 가능.

### 2-1. 프롬프트 앵커 강화 (즉시, 비용 0)
- v3 §3 템플릿을 **불변 상수 블록**으로 코드에 고정하고(복붙 변형 금지), 다음을 추가:
  - 스타일 토큰에 `matte painterly, muted highlights` (1-5 무광 결정 반영)
  - 계절 토큰 `late summer foliage` (수종 프롬프트에만, 1-3 결정 반영)
  - 금지어(네거티브/회피) 확장: `glossy, shiny, candy, cute, cartoon mascot, specular highlight`
- 한계 인지: 프롬프트만으로는 배치 간 드리프트를 못 막는다. 앵커는 "평균을 맞추는" 장치이고
  분산은 아래 2-2~2-3이 잡는다.

### 2-2. 후처리 통일 확장 — 하모나이즈 v2 (반나절, 효과 최대)
현 하모나이즈(채도 클램프+화이트밸런스)에 3단 추가. 순서대로:
1. **레퍼런스 통계 매칭**: 확정 반입물(예: oak 확정본 + 잔디 램프)을 "톤 앵커 세트"로 지정,
   신규 에셋의 LAB 평균·표준편차를 앵커 세트에 소프트 매칭 (Reinhard color transfer,
   강도 0.3~0.5 블렌드 — 100% 매칭하면 개성이 죽음). `scikit-image match_histograms`로도 대체 가능.
2. **카테고리별 명도 클램프 테이블** (1-1·1-2 결정을 숫자로):

   | 카테고리 | V 범위 | S 상한 |
   |---|---|---|
   | 지형 타일 | 0.20~0.60 (+전체 -10% 시프트) | 0.45 |
   | 정적/인터랙티브 오브젝트 | 0.20~0.85 | 0.65 |
   | 캐릭터 | 0.25~0.92 | 0.75 |
   | 포인트 컬러(단풍·경고) | — | 0.85, 화면당 소량 |

3. **공용 마감 LUT 1장**: 위 단계를 통과한 결과에 마지막으로 동일 LUT(또는 동일 톤커브)를 일괄 적용.
   "같은 카메라로 찍은" 느낌을 주는 마감 패스. LUT은 확정 반입물 세트에서 1회 추출해 고정.
- 이 층이 생성형 파이프라인의 **가장 가성비 높은 통일 장치**다 — 생성 품질이 흔들려도 출구에서 톤이 수렴한다.

### 2-3. 큐레이션 정량 게이트 + 통계적 선별 (반나절)
- 배치(시드 3~6안) 생성 후, 후보별로 자동 산출: 평균 V / S 상한 초과 픽셀 비율 / 지배 hue의 램프 이탈 각도.
- **앵커 세트 통계와의 거리(distance)로 정렬** → 가까운 후보를 우선 노출, 이탈 후보는 자동 탈락.
  "사람 눈 큐레이션"을 대체하는 게 아니라, 사람이 보기 전에 톤 불합격을 걸러주는 프리필터.
- 부수 효과: 바닥 요소(캐스트 섀도·흙받침) 검출도 여기에 넣을 수 있음 (하단 영역 저명도 블롭 검사).
- 컨택트시트 자동 생성(신규 후보를 기존 반입분 옆에 배치)을 게이트 산출물로 — v3 큐레이션 6번 의무의 자동화.

### 2-4. 레퍼런스 이미지 컨디셔닝 (1일, 도구 검증 필요)
- **img2img 저강도**(denoise 0.25~0.4): 러프 실루엣이나 기존 반입물을 초기 이미지로 넣고 재생성 —
  구도·톤이 레퍼런스에 끌려온다. 신규 카테고리(가구 등) 첫 진입 때 특히 유효.
- **IP-Adapter / Redux 계열 스타일 레퍼런스**: 확정 반입물 이미지를 스타일 조건으로 주입.
  FLUX 생태계에서 어댑터 호환(schnell vs dev) 확인 후 도입. 시드 고정은 같은 프롬프트 골격 내
  구도 재현엔 유용하나 스타일 통일 장치로는 약함 — 시드는 "스윕 후 선별"용으로만.

### 2-5. 자가 스타일 LoRA (반입물 쌓이면 — 최종 병기)
- 확정 반입물 **30~50장**(1024px 업스케일 스틸) 모이면 로컬 ai-toolkit으로 스타일 LoRA 훈련.
  트리거 토큰 1개(예: `pwsim_style`), rank 8~16 소형이면 충분. 훈련 셋은 하모나이즈 **통과본**으로 —
  그래야 LoRA가 "우리 톤"을 배운다.
- 프롬프트 앵커+LoRA 조합이 되면 신규 배치의 탈락률이 급감 → 로드맵 4단계(가구·건물, 물량 최대)
  **진입 전**에 훈련하는 것이 투자 대비 최적 타이밍. 현재 나무 5종+광맥 4종 ≈ 확정본 9~12장이라 아직 부족;
  3단계(지형 타일)까지 쌓고 실행.

## 파트 3 — 현 반입물 톤 진단 (12·13번 큐레이션 시트)

1. **계절 불일치 (나무 시트)**: oak=한여름 진초록, birch=가을 노랑, maple=진홍 절정, spruce=청록.
   개별 품질은 좋으나 한 맵에 깔리면 계절이 섞여 보임 — §1-3 결정이 선행돼야 birch 재처리 방향이 정해진다.
   spruce는 지배색이 그린 램프에서 청회색 쪽으로 이탈(±15° 규칙 경계) — 하모나이즈로 녹색 방향 시프트 권장.
2. **광맥 명도 산포 과대 (바위 시트)**: marble은 근순백(V 0.92 상한 초과 소지), granite는 근흑.
   인게임에서 marble 광맥이 캐릭터보다 밝아 시선을 강탈 → 밸류 위계(§1-1) 붕괴 1순위 요인.
   후처리에서 marble V≤0.85 클램프·granite 미드톤 +10% 리프트로 두 극단을 중앙으로 모을 것.
3. **셰이딩 결 불일치**: 나무 일부(oak 1·2안, pine 1안)는 유광 캔디 블롭 셰이딩, 바위는 무광 매트 —
   나란히 두면 출처가 다른 두 팩처럼 읽힌다. §1-5 무광 확정 시 나무 쪽 재생성(금지어 반영) 또는
   하이라이트 압축 후처리로 수렴 가능. 부수: 바위엔 아웃라인이 없어 §1-4 결정도 함께 필요.
4. (경미) 바닥 요소 잔존: oak 3안 흙받침, boulder 한 안의 강한 캐스트 섀도 — v3 §4-4 기존 규칙 사항,
   §2-3 게이트로 자동 검출 전환 권장.
