# PawnSim — 전체 기획서 (GDD)

**v1.0 초안 — 2026-07-24**
운영자 지시: "지금 구현된 거 기준으로 기획서 만들고, 빠진 부분 보강하고 뺄 거
빼가면서, 기획서 베이스로 제작해야 게임 완성도가 오를 듯."

> **이 문서의 지위**: 게임 내용의 기획 정본. 이후 모든 기능·밸런스·아트 작업은
> 이 문서(및 §8의 세부기획서 세트)에 근거를 둔다. 문서에 없는 기능은 먼저 문서에
> 추가(운영자 승인)한 뒤 구현한다. 작업 큐 운영은 기존대로 goal.md → 로드맵이
> 담당하고, GDD 는 "무엇이 게임인가"를 담당한다.
>
> **표기 규칙**: 각 시스템에 4상태 판정 —
> ✅유지(현행 확정) · 🔧보강(스펙대로 수정·확장) · ✂️컷(제거·숨김) · ⏸보류(스코프 밖).

## 1. 컨셉

- **한 줄**: 조난당한 3~4명의 생존자가 황야에 정착지를 짓고, AI 스토리텔러가
  던지는 위기를 넘기며 **저마다의 이야기를 만들어가는** 콜로니 시뮬레이션.
- **장르**: 콜로니 시뮬레이션 (톱다운 2D, 간접 조작 + 부분 직접 조작(드래프트)).
- **레퍼런스 정합 원칙**: 장르 바닐라 수치와 최대한 유사하게 (운영자 지시,
  `balance-parity-2026-07-25.md` 가 수치 정본).
- **플랫폼**: WebGL(제출 본선) + Windows(영상 촬영용). 한국어 단일.
- **세션 목표**: 첫 10분 안에 "살아있는 콜로니"가 체감될 것 — 심사자 동선
  (`gameplay-audit-2026-07-24.md` §4) 이 첫인상 기준.
- **컨텍스트**: NHN NAN 2026 사전과제 (마감 8/10). 단 제출 준비보다 게임 자체
  완성도가 우선 (운영자 지시).

## 2. 플레이어 판타지와 코어 루프

**판타지**: "내가 키운 사람들" — 유닛이 아니라 개인으로 읽히는 콜로니스트들이
살아남고, 부딪히고, 성장하는 이야기의 관찰자 겸 연출가.

**이중 루프** (장르 뼈대 리서치 정합 확인됨):
- **내부 루프(분 단위)**: 니즈·무드·식량 감시 → 작업 지정/우선순위 → 건설·생산
  → 이벤트 대응.
- **외부 루프(일 단위)**: 연구 → 정착지 확장 → 정착지 가치 상승 → 위협 에스컬레이션
  → 더 나은 방어·설비.

**첫날 리듬(온보딩 고정 시퀀스)**: 저장구역 → 집(벽·지붕·침대) → 농장 → 방어.
튜토리얼 게이트가 이 순서를 안내한다 (구현됨 — 유지).

## 4. 밸런스 원칙

- **정본**: `balance-parity-2026-07-25.md`. 원칙 = **바닐라 정합 우선, 의도적 이탈은
  문서에 명시된 것만** (세션 페이싱 압축: 작물·나무 성장, 첫 습격 시점 등 C군).
- 시계 1게임일 = 1,000초(1x) — 바닐라 1:1 정합 확인됨. "per day" 수치는 /1000 환산.
- 실행 순서: **A군(즉시 안전 6건) → B군(소크 동반 10건, 무드·수면·식사는
  human-rhythm 4일 소크 "붕괴 0~1·바닥기상 0" 재검증 필수) → C군(운영자 판단 8건)**.
- 무드 모델 전환(B1)은 D-A(a) 승인 튜닝을 대체하므로 단독 라운드로.

## 5. 보강 우선순위 (기획서 베이스 개발 큐)

첫인상 크리티컬(심사자 10분 동선) × 운영자 승인 상태 기준:

1. **A1 부패 버그 2줄** + A군 잔여 (즉시, 무소크)
2. **정직화 일괄** (상인 카드 문구·질병 재라벨·울타리 툴팁·ThreatAlertUI 제거 — 전부 코스메틱급)
3. **멘탈브레이크 3티어** (승인 완료, 스펙 `spec-needs-mood-balance.md` Phase 2)

6. **B군 밸런스 소크 라운드** (B1 무드 모델은 단독 라운드)
7. 아트 v3 잔여 단계 (지형→가구·건물[벽 오토타일]→동물→림[무기 오버레이 포함])
