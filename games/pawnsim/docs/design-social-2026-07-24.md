## G1. 사회 상호작용 최소형 — "잡담"

### 목표
10분 관찰에서 "림들이 서로를 인식한다"는 신호 1개를 만든다. 관계 시뮬레이션이
아니라 **살아있음의 증거**가 스코프다. (풀 관계망·연애·다툼 = 스코프 밖)

### 동작 스펙
1. **트리거**: 두 림이 거리 ≤2칸 + 둘 다 (idle/여가/식사 중) + 둘 다 수면·징집·
   붕괴·다운 아님 + 마지막 잡담으로부터 쌍(pair)당 쿨다운 경과.
2. **연출**: 두 림 머리 위 말풍선 아이콘(💬 대신 폰트 무의존 스프라이트 —
   게이지바 전례) 2.5초 + 서로 마주보기(Facing 전환). 이동 정지 없음(일하며
   지나치듯 — 노동 손실 0).
3. **효과**: 양쪽에 thought "즐거운 대화" +2 (지속 0.4게임일). PawnThoughts
   카탈로그 1행 추가.
4. **호감도**: pair 호감도 int (−100~100, 초기 0). 잡담 1회당 +2 (상한 도달 시
   무증가). 인스펙터 사회 탭(또는 상태 탭 1줄)에 "가장 친한 동료: <이름> (+N)"
   표시. 라벨(친구/앙숙)·행동 분기는 2단계 — 이번 스코프 아님.
5. **socialMul 배선**: 잡담 쿨다운에 socialMul 역수 적용 (사교적 림이 더 자주).
   기존 거래 가격 배선은 유지.

### 수치 (초기값 — 소크로 조정)
| 항목 | 값 | 근거 |
|---|---|---|
| 잡담 거리 | ≤2.0칸 | 기존 모닥불 모임 반경과 결 맞춤 |
| 쌍당 쿨다운 | 0.25게임일(250초) × (1/socialMul) | 하루 3~4회/쌍 상한 |
| thought | +2, 0.4일 지속 | D-A(a) 양성 thought 크기 결과 맞춤 — 무드 economy 왜곡 방지 |
| 호감도 증가 | +2/회 | 10일 ≈ +60~80 (세션 내 가시 변화) |
| 붕괴 중 잡담 | 금지 | 붕괴 연출 보호 |

### 검증 (재현-우선)
- repro 시나리오 `p2-social-chat.json`: 두 림을 인접 idle 로 두고 300초 시뮬 →
  assert 잡담 이벤트 ≥1 + thought 존재 + 호감도 >0.
- human-rhythm 소크 1회: 무드 평균이 D-A(a) 승인 범위(붕괴 0~1) 유지 확인
  (+2 thought 추가가 무드 인플레를 만드는지).
- 스크린샷: 말풍선 노출 컷.

### 구현 노트
- 신규 `PawnSocial.cs` (per-pawn): 스캔은 1.5초 Decide 주기에 편승 (신규 Update
  루프 금지). ReservationManager 불요(비배타 — 동시 잡담 허용, pair 중복만 쿨다운).
- 세이브: pair 호감도 dict<(id,id),int> — SaveLoadManager v14 필드. 로드 시 없으면
  빈 dict (하위호환).
- 말풍선: SpriteRenderer 월드 오브젝트 (BlueprintEntity 게이지바 패턴 재사용).

## G3. 무덤·매장 — 죽음의 의식

### 목표
시체가 "영원히 방치되는 쓰레기"에서 "이야기의 마침표"가 되게 한다.

### 동작 스펙
1. **무덤 건축물**: Architect 가구 탭 "무덤" — 1×2, 목재 0/석재 0 (맨땅 파기,
   노동 8초). 완성 시 빈 무덤(봉분 없는 흙 자리 스프라이트).
2. **매장 job**: 빈 무덤 존재 + 시체 존재 시 Haul 파이프라인 재사용 (시체 =
   특수 hauling 대상). 운반 → 무덤에 안치 → 봉분 스프라이트로 전환 + 이름 각인
   (인스펙터에 "여기 <이름> 잠들다 — <배경 한 줄>").
3. **thought**: 매장 완료 시 전 콜로니 "동료를 묻어줌" +3 (0.5일). 기존
   "동료 사망" −15 는 유지 (상쇄가 아니라 애도의 마무리).
4. **미매장 방치 압박**: 시체 존재 3일차부터 전 콜로니 "방치된 시체" −3
   (시체가 치워질 때까지 갱신). 매장 동기 부여.
5. 파묘/이장/장례식 = 스코프 밖 (확장 금지 — 오딧 §2 G3 최소형 준수).

### 수치
| 항목 | 값 |
|---|---|
| 무덤 크기/비용/노동 | 1×2 / 자재 0 / 8초 |
| 매장 우선순위 | Haul 카테고리 내 최상단 (시체 > 일반 더미) |
| 묻어줌 thought | +3, 0.5일, 전원 |
| 방치 시체 thought | −3, 시체 존재 3일차부터 |

### 검증
- repro `p2-grave-burial.json`: 림 1 사망 강제 → 무덤 지정 → 매장 완료 assert
  (시체 소멸 + 봉분 + thought 존재).
- 세이브 라운드트립: 봉분+각인 이름 복원.

### 구현 노트
- `GraveEntity.cs` (빈/안치 2상태 + 각인 문자열). StructureTag 재구성 경로 포함
  (세이브 §12 패턴).
- 시체는 현재 PawnEntity 잔존+틴트 방식 — 매장 시 Destroy + GraveEntity 에 이름/
  배경 이관.
- 아트: 아트 v3 가구·건물 단계에서 무덤 2상태 스프라이트 포함 (시안-퍼스트 적용).
