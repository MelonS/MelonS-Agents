# 디자인 QA — 아트 반입 게이트 (정본)

**신설 2026-07-24.** 계기: 지형 타일 1세대가 행동 게이트(repro 16종)를 전부
통과하고도 운영자에게 "너무 심각해, 스웨터 같아, 아무것도 안 보여"로 반려됨.
행동 게이트는 미적 품질을 아예 측정하지 않으며, 제작자(메인 에이전트)의 자기
판정은 제작 편향 때문에 신뢰 불가라는 것이 증명됨.

운영자 지시 3건이 이 문서의 뼈대:
1. "디자인을 검수하는 QA가 따로 있어야 할 듯" → **TA 격리 채점**
2. "TA라고 해야 하나… 아트 관련 전담이 있어야 할 듯" → **`.claude/agents/ta.md` 전담 롤**
3. "아트도 바로 적용할 게 아니라 **시안 먼저 만들고 적용**해야 할 듯" → **시안-퍼스트 원칙**

## 아트 반입 5단계 (모든 비주얼 자산 의무)

```
① 시안 제작 (후보 2~4안, 인게임 맥락 모사 뷰 포함)
        ↓
② TA 채점 (격리 에이전트 — 루브릭 5항 + 자동 메트릭)
        ↓ TA PASS 안만
③ 운영자 픽 (시안 폴더 경로 제시 — G:\ai\_pawnsim_시안\)
        ↓ 픽 받은 안만
④ 인게임 적용 + 빌드 → 실제 인게임 스크린샷 TA 재채점
        ↓ PASS
⑤ 운영자 인게임 확인 → 커밋
```

- **①→③ 전에 unity-project/Assets 에 반입 금지.** 시안은 스크래치패드와
  시안 폴더에만 존재한다. (2026-07-24 타일 사고의 직접 교훈)
- ④의 인게임 스샷 재채점은 생략 불가 — 단품·모자이크가 예뻐도 실줌·실맥락에서
  죽는 사례가 반복됨 (스웨터는 모자이크 검사로도 통과됐었다).
- 운영자에게 시안을 보여줄 때는 **전체 경로**를 명시한다 (링크만 주면 못 찾음
  — 운영자 피드백).

## TA (테크니컬 아티스트) 롤

- 정의: `.claude/agents/ta.md` (세션 등록 전에는 general-purpose 에 동일 프롬프트
  인라인으로 스폰).
- 권한: 아트 자산의 커밋 게이트. TA FAIL 자산은 수정 지시 이행 후 재채점.
- 루브릭 5항 (각 1~10, 전항 ≥7 = PASS): 가독성 / 반복 아티팩트 / 톤 순응(v3.1)
  / 씬 조화 / 장르 정합.
- 원칙: 애매하면 FAIL. "운영자에게 보여도 부끄럽지 않은가"가 마지막 질문.

## 자동 메트릭 (판단 보조 — 판정 대체 불가)

**합의 정의 (TA 1차 채점에서 확정)**: 로컬 콘트라스트 = `mean |pix − gaussian(σ=3)|`
(그레이스케일, /255). 제작자·TA 가 같은 정의로 측정할 것 — 1차 채점에서 정의
불일치로 13.1 vs 18.5 가 갈렸다.

| 메트릭 | 기준 (지형) | 잡는 사고 |
|---|---|---|
| 로컬 콘트라스트 (위 정의) | 잔디·흙 ≤6, 돌 ≤8 (예외 상한), 물 1~3 | 스웨터/니트 (고주파 노이즈) · 과평탄(플레이스홀더 색면) 양쪽 |
| 인접 셀 밝기차 (Weber) | ≤2% | 체커보드/퀼트 |
| 수직축 미러 상관 | <0.4 | 만화경/나비 모티프 |
| 셀 경계 연속성 | 경계 8px 공통 베이스 페더 or 부모 오프셋 샘플링 | 셀 경계 직선 시임 |
| 이음새 경계차 (wrap) | 시각 검사 병행 | 격자선 |
| 채도 상한 | 지형 0.45 / 오브젝트 0.65 / 캐릭터 0.75 | 톤 이탈 (v3.1) |
| 평균 밸류 | 지형 0.42~0.50 밴드 | 너무 어두움("아무것도 안 보여") |
| 자기상관 주기성 | 낮을수록 위험 | 모티프 반복 |

측정 스니펫은 세션 스크래치패드 `art_v3/` 참조 — 재사용 시 스크립트화한다.
