# PawnSim Art v2 스타일 스펙 (16px → 32px 마이그레이션)

대상: 스프라이트 생성기 작성자. 이 문서만으로 질문 없이 생성 가능해야 함.
팔레트 원본: `Assets/Sprites/palette.py` (단일 진실 소스 — 생성기에서 import, 색 하드코딩 금지).

---

## 1. 팔레트 규칙

- **기존 램프 전부 유지** (GRASS/DIRT/ROCK/WATER/WOOD 3단, SKIN 2단, CLOTH 3종 + DK/TROUSER 파생). 값 변경 금지.
- **확장 규칙**: 새 색이 필요하면 기존 램프 앵커에서 HSV 파생만 허용 — 명도 ±12% 이내, 채도는 해당 그룹 밴드 유지. 새 hue 추가는 스펙 개정 필요.
- **계층**: 지형 = 저채도(웜톤, 화면에서 후퇴) / 림·아이템·작물 = 고채도 포컬(CLOTH_*, CROP_GOLD, FIRE_*) / **DANGER_RED는 적·HP위급 전용 예약** — 베리·고기 등 빨강 계열은 MEAT_RED 사용.
- 의상 금지 휴밴드: 잔디 녹색대(hue 90~150°) — 림 보호색 방지 (TOP-4 교훈, palette.py 주석 참조).

## 2. 32px 공통 규칙

| 항목 | 값 |
|---|---|
| PPU | 32 (셀 = 1 유닛 **불변**, 코드 수정 없음) |
| 외곽선 | **1px** — 림/동물 `OUTLINE_STORY`, 사물/건물 `OUTLINE_OBJ`, 식생 `OUTLINE_PLANT`(또는 무외곽). v1의 2px 림 외곽선은 폐기 |
| 조명 | 좌상단 고정. 좌상=LT, 우하=DK |
| 음영 | **디더링 금지.** 플랫 채움 + 램프 2단(MD 베이스 / DK 그늘, 필요 시 LT 하이라이트 소량) |
| 임포트 | Point filter, 압축 없음, PPU 32 |

## 3. 림(콜로니스트) 규격

- 프레임 32×32. 신체 비례(프레임 내, y는 위에서): 머리카락 y2–8, 얼굴 y8–14, 몸통 y14–23, 다리 y23–29, 바닥여백 y29–31. 발밑 1px `OUTLINE_STORY` 접지 그림자.
- **3방향**: S(정면) / E(측면, W는 flipX) / N(뒷면 — 얼굴 없음, 머리카락이 얼굴 영역 덮음).
- 의상 3변형: blue / rust / olive(=머스터드) — CLOTH_* + CLOTH_*_DK + TROUSER_* 사용.

**애니메이션** (시트 1장 256×96, cols=프레임 8, rows=방향 3 — row0=S, row1=E, row2=N):

| col | 프레임 | 내용 |
|---|---|---|
| 0 | idle | 중립 1프레임 |
| 1–4 | walk 4 | F1 오른다리 앞 +2px / F2 패스(중립) / F3 왼다리 앞 +2px / F4 패스. 다리 교차 ±2px, 팔 역스윙 ±1px. F2·F4에서 몸통 y+1px 바운스 |
| 5–6 | work 2 | F5 들어올림(팔+도구 위로, 손 y−1) / F6 내려침(팔+도구 앞으로, 손 y+1) |
| 7 | 예약 | 투명 |

## 4. 도구 오버레이

- 도끼 `tool_axe`, 곡괭이 `tool_pickaxe`: 각 **12×12**, 별도 PNG. 손잡이 WOOD ramp, 날 ROCK_LT(+ROCK_MD 음영), 외곽 `OUTLINE_OBJ` 1px.
- 도구 그립 앵커(도구 스프라이트 내): **(3,10)** — 자루 하단.
- 림 손 앵커(프레임 좌상 원점, 그립이 닿는 픽셀):

| 방향 | 손 앵커 | 비고 |
|---|---|---|
| S | (22, 20) | 오른손, 도구는 림 **앞** 레이어 |
| E | (21, 20) | 진행방향 손, 림 앞 레이어 (W=flipX 시 앵커도 미러: x→31−x) |
| N | (9, 20) | 뒷면이라 좌우 반전, 도구는 림 **뒤** 레이어 |

- work F5: 도구를 그립 기준 −45° 회전 느낌으로 위쪽 배치, F6: 0°로 전방 하단. (픽셀아트이므로 회전은 프리렌더 — 도구 시트에 raised/strike 2포즈 포함해도 무방, 그 경우 24×12 가로 2칸.)

## 5. 지형 타일 32×32

- 내부 디테일 밀도 **~10%** (테두리 제외 30×30 = 900px 중 ~90px만 DK/LT 점·풀잎, 나머지 MD 플랫). v1의 전면 노이즈("QR코드 지면") 금지.
- **변형 간 평균 명도차 압축** (TOP-1 교훈): 변형별 평균 휘도가 베이스 MD 대비 ±2 이내. 명도 변형이 아니라 디테일 *배치* 변형으로 구분.
- **테두리 1px = 순수 베이스색(MD)** 링 — 타일링 심리스 보장. 디테일 픽셀은 테두리에 닿지 않음.
- 종류·변형: grass ×4, dirt ×2, rock ×2, water ×2 (water만 LT 잔물결 가로선 허용, 디더 아님).
- 시트: 종류별 1행 가로 나열 (`tiles_grass_v2.png` = 128×32 등).

## 6. 식생

- **나무**: 32×48 (캐노피가 셀 위로 16px 돌출, 피벗 하단 셀 기준). 캐노피 **비대칭** 실루엣 3변형 + 그루터기 1(하단 32×16만 사용) + 묘목 1(중앙 소형) = 시트 `tree_v2.png` 160×48, 5칸. 캐노피 GRASS_DK 베이스+GRASS_MD 좌상 광, 줄기 WOOD ramp, 윤곽 `OUTLINE_PLANT`.
- **베리덤불**: 32×32 단일. 둥근 녹색 베이스(GRASS_DK/MD) + **빨강 점 2×2px ×4개** 비대칭 배치 — 색은 `MEAT_RED`(DANGER_RED 금지). 수확 후 상태 1프레임(점 없음) 포함 → 시트 64×32, 2칸.

## 7. 아이템 (바닥 드롭/스택)

- 캔버스 32×32, 실제 드로잉 **~20×16** (칸의 0.6), 하단 중앙 정렬. 외곽 `OUTLINE_OBJ` 1px.
- 고유 실루엣 (색만 다른 사각형 금지):
  - `item_wood` 통나무 가로 3단 쌓기 (WOOD ramp, 단면 LT 원)
  - `item_stone` 각진 다면체 덩어리 (ROCK ramp)
  - `item_meat` 고기 슬랩 (MEAT_RED + SKIN_SH 지방 라인)
  - `item_meal` 간편식 팩 (UI_CREAM 포장 + CROP_GOLD 띠)
- 스택 3단계: s1(1개) / s2(중간, 2~3개 겹침) / s3(만재, 가득 + 높이 증가). 시트 가로 3칸 96×32.
