## 1. 삐 소리 — `ambient.wav`

**측정으로 특정했다** (귀 대신 스펙트럼). 지속 재생되는 루프 3종을 비교:

| 파일 | tonality | 지배 주파수 | 판정 |
|---|---|---|---|
| `ambient.wav` (기존) | **672.9** | **200.0Hz 12.2% + 400.0Hz 10.2%** | 순음 드론 = 삐 |
| `bgm_ambient.wav` | 655 | 260/347/439Hz 분산 | 화음 패드 — 정상 |
| `ambient_night.wav` | 94.9 | 8.4kHz 대역 분산 | 벌레소리 — 정상 |

딱 떨어지는 200/400Hz(기본음+2배음)는 합성 사인의 지문이다.
GDD 는 "BGM 삐소리 해결됨"이라 기록하고 있었고 **그건 사실이었다** — 고쳐진 건
`bgm_ambient.wav` 였고, **바로 옆의 주간 앰비언트가 누락**됐던 것.
`AudioBank.cs` 주석은 이 파일을 이미 "wind/birds bed"로 기술하고 있어,
코드 기대와 에셋 실물이 어긋난 상태이기도 했다.

조치: `_gen_m7_day_ambient.py` 신설 — 전 구간 노이즈 기반(원폴 필터 바람 + 짧은
FM 처프 새소리), 등파워 크로스페이드로 심리스 루프. 배선 변경 없음(파일만 교체).

**결과: tonality 672.9 → 21.4, 최대 피크 12.2% → 0.08%.**

## 2. tofu — 폰트에 없는 문자가 빈칸으로

`✕ ⚔ ⛏ 🔨 🛏 📦 🔒 🍇 🌾 …` 등이 번들 폰트 3종
(DNFBitBit / GowunDodum / NotoSansKR) **어디에도 없었다.**
Unity 는 이런 코드포인트를 예외 없이 빈칸으로 그린다 — 조용한 실패다.

가장 눈에 띄던 곳: **우클릭/좌클릭 컨텍스트 메뉴**가 "▯ 건설 우선", "▯ 수면"
처럼 보였고, 건축 셸프의 제거 도구 셀은 **통째로 빈 상자**였다.

조치:
- 정보를 담은 기호는 안전 문자로: `✕→×`, `✓→○`, `✗→×`, `▸→▶`, `⚔→△`, `❚→|`
- 장식 이모지는 제거하고 한글 레이블만: `"🔨 건설 우선"` → `"건설 우선"`
- 51개 파일 변경.
- **`scripts/check-font-coverage.py` 신설** — 폰트 cmap 과 UI 문자열을 대조하는
  게이트. 수정 전 exit 1 / 수정 후 exit 0 로 양방향 확인함.

## 3. 컨텍스트 메뉴가 엉뚱한 곳에 뜨던 진짜 원인

`ContextMenuUI.Open` 이 **좌표계를 섞어 쓰고 있었다**:

- `ScreenPointToLocalPointInRectangle` → 캔버스 **pivot(중앙) 원점** 좌표 반환
- 패널은 `anchorMin=anchorMax=(0,0)` → `anchoredPosition` 은 **좌하단 원점** 해석

변환 없이 대입해서 메뉴가 클릭 지점에서 **(W/2, H/2) 만큼 어긋났다.**
클램프가 화면 안으로 되돌려놓는 바람에 "어디를 눌러도 좌하단 근처"가 됐고,
운영자에겐 "취소버튼이 이상한 곳에 있음"으로 보였다.

조치: `localPos -= (cr.xMin, cr.yMin)` 로 좌하단 기준 변환 후 클램프.

## 4. 건축 패널 층 분리

건축 패널/셸프는 화면 바닥 y=8, 하단 컨트롤바는 y=24~96 — **같은 높이 띠**에
가로로 나란히 놓여 하나의 연속된 바처럼 읽혔다.
`PanelBottomY = 104` 로 올려 컨트롤바 위층으로 분리.

부수 정리: `PawnInfoPanel` 이 셸프 높이를 `108f + 95f * (rows-1)` 로 **복제**하고
있어서 패널을 옮기면 한쪽만 따라가 겹치는 구조였다.
`ArchitectMenu.ShelfTopY` 하나로 통합해 소유권을 단일화.

## 5. 회전 (R)

`SizeFor(mode)` 는 "원래 크기"라는 순수 함수로 두고, 회전은
`EffectiveSizeFor(mode)` 에서만 얹는다 — 이 분리가 없으면 비용 계산·저장 등
`SizeFor` 를 쓰는 다른 경로가 회전에 오염된다.

핵심: **90° 회전이 월드 가로/세로를 알아서 교환하므로 스케일 계산은 그대로 둔다.**
로컬 (1,2) + 90° → 월드 (2,1). 콜라이더도 같은 transform 을 타므로 함께 돌아간다.

일관성 체인 (하나라도 빠지면 티가 난다):
- 고스트: 중심은 회전 반영 크기, 스케일은 회전 전 크기 + transform 90°
- 점유 검사: `EffectiveSizeFor` (가로 침대는 가로 2칸)
- 청사진: `SetSize(회전전크기, rotated)`
- 완성물: `BlueprintEntity.isRotated` → `SpawnFinished(..., rotated)`
  (안 넘기면 **다 짓는 순간 침대가 홱 돌아간다**)
- 세이브: `StructureTag.rotated` → `StructureSave.rotated` → 로드 시 복원
  (구버전 세이브는 필드 부재 → false = 실제 상태와 일치, 마이그레이션 불필요)

키 충돌: `R` 은 평소 징집 토글이라 `ClickSelector` 에 `!buildActive` 가드 추가.
없으면 침대를 돌릴 때마다 선택된 림이 같이 징집된다.

검증: `repro-scenarios/p3-rotate-bed.json` — 세로 배치 → R → 가로 배치 → 캡처.
