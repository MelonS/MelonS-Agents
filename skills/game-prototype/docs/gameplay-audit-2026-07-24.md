## 1. 리서치 요약 — 장르의 뼈대

### 1-a. 신규 플레이어 첫 1~2시간의 재미 뼈대 (가이드/케이스 스터디 종합)

1. **이중 루프**: 내부 루프(니즈/무드/식량 감시 → 일 할당 → 건설 → 이벤트 대응)
   + 외부 루프(연구/확장/위협 에스컬레이션). → PawnSim 은 **양쪽 다 보유**.
2. **첫날 리듬은 고정**: 지붕·저장구역·침대·식량(빠른 작물) → 방어(엄폐물) → 조명.
   → PawnSim 튜토리얼 게이트(저장→집→농장)가 이 리듬과 **정확히 일치**.
3. **감정 훅**: 콜로니스트가 "교체 가능한 유닛"이 아니라 **한 명의 사람**으로
   읽히는 순간 애착이 시작됨 — 배경서사·트레잇·스킬이 클릭 3초 안에 읽혀야 함.
4. **스토리텔러의 존재 증명**: 이벤트 레터가 "누군가 내 콜로니를 지켜보며 이야기를
   만들고 있다"는 감각을 줌. 초반 1시간 안에 최소 1~2회의 드라마 비트 필요.

### 1-b. 커뮤니티의 "이게 없으면 콜로니심이 아니다"

1. **개별 캐릭터 시뮬레이션** — 니즈·작업 우선순위·트레잇·스킬·스케줄.
   장르 정의 아티클이 공통으로 꼽는 **장르의 정체성 그 자체**. → PawnSim 5/5 보유.
2. **무드 → 멘탈브레이크의 다양성** — "무해한 배회부터 폭력 사태까지"의 스펙트럼이
   시그니처로 인용됨. → PawnSim 은 단일 배회만 (기존 phase1 #14 재확인).
3. **콜로니스트 사이의 창발 서사** — 우정/경쟁/관계가 무드·생산성에 환류.
   "레이아웃이 아니라 **사람을 기억한다**"가 장르의 서명. → PawnSim **부재** (§2 G1).
4. **구역/저장/운반 우선순위** — → 보유 (5-tier 스톡파일 + 운반).
5. **위협 페이싱** (스토리텔러 모드) — → 보유 (3 디렉터 모드 + tier).

### 1-c. 커뮤니티의 "복잡하기만 하고 없어도 되는" 것

레퍼런스 콜로니심 커뮤니티가 반복적으로 피로를 호소하는 지점 — **PawnSim 이
안 갖고 있는 게 오히려 강점**인 목록:

| 피로 요소 | PawnSim 현황 | 판정 |
|---|---|---|
| 장비/방어구 미세관리 (착탈 타이밍·이동 페널티) | 장비 최소형(방어구+공격 보너스) | **현 수준 동결** — 확장 금지 |
| 작업표+빌 큐의 이중 미세관리 | 빌 큐 없음 (스코프 밖 유지 중) | **계속 스코프 밖** — 재확인 |
| 대규모 콜로니 후반 피로 | 3~4명 소규모 | 해당 없음 |
| 수술 실패 RNG·블라이트(작물 역병) | 없음 | **도입 금지** (커뮤니티가 명시적으로 "재미없는 RNG"로 꼽음) |
| 의복 마모/오염(tainted) 관리 | 없음 | **도입 금지** |
| 침대 소유권 재할당·나무 한 그루씩 재식목 | 없음 (자동 재생 `RegrowthScheduler`) | 현 자동화 유지 |
| 전투 전원 수동 미세조작 | 드래프트+자동공격 | 현 수준 적정 |

→ **결론: "빼야 할 장르 요소"는 대부분 애초에 안 넣었음.** 기능추가 보수 원칙이
맞았다는 방증. 제거 후보는 장르 요소가 아니라 §3의 **자체 데드웨이트**.

→ (운 좋으면) 이벤트 1회. 이 10분에서 체감되는 순서로:

1. **림들이 서로를 모른다 (G1)** — 10분 내내 가장 오래 보는 화면은 "림들이
   일하는 모습"인데, 상호 인식 0 이면 콜로니가 아니라 **개별 AI 데모**로 읽힘.
   말풍선 잡담 하나가 "살아있음"을 증명하는 최저비용 신호.
2. **클릭한 림이 '누구'인지 3초 안에 안 잡힘 (G2)** — 심사자는 반드시 림을
   클릭한다. 바 4개+스킬 숫자는 나오지만 **이야기가 0줄** → 애착 훅 불발.
3. **첫 10분 레터 0장 리스크 (G5)** — 스토리텔러(AI Director)는 이 프로젝트의
   포트폴리오 헤드라인인데, 짧은 세션에서 발화가 안 보이면 존재 증명 실패.
4. **멘탈브레이크가 조용함 (기존 phase1 #14 재확인)** — 무드가 떨어져도 배회
   뿐이라 드라마가 비가시. "폭발하는 림" 1회가 장르 서명의 절반.
5. **빈 인터랙션 (R1/R2)** — 교역 NPC 클릭 무반응, 죽은 스탯 노출. 있는 걸 못
   만든 것보다 **있는 척한 게 안 되는 것**이 심사에서 더 감점.
