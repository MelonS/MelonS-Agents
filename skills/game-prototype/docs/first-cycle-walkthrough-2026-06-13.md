# 첫 사이클 플레이어 UI 워크스루 (2026-06-13)

운영자 목표("처음에 저장공간을 설정하고 살 집을 짓고 농사 지역을 설정하고 그런
기본부터 충실히 구현")의 **플레이어 시점 UI 흐름**을 한 장으로 증빙한다.
격리 채점은 효과를 검증하지만, '플레이어가 실제로 이렇게 조작한다'는 화면 증거가
없었던 갭을 채운다.

![첫 사이클 9단계 워크스루](demo/first-cycle-walkthrough-2026-06-13.png)

## 9단계 (전부 주간, 현재 빌드 = 신아트 작물·나무·광맥 반영)

| # | 화면 | UI 상태 |
|---|---|---|
| 1 | 시작 | 일시정지로 시작 — 둘러보고 1배속으로 시작(사람-리듬 #1) |
| 2 | 건축 메뉴 | 하단 건축 패널: 지시/구역/생산/구조/가구/바닥 카테고리 |
| 3 | 저장 도구 | 구역→저장 선택, 상단 "저장 구역 리툴 중 — 우클릭/ESC 해제" 배너 |
| 4 | 저장공간 설정 | 4셀 드래그 지정 → 노란 저장 구역 마커 |
| 5 | 벽 도구 | 구조→목재 벽, 목재 자원 표시(100+190 바닥) |
| 6 | 집 청사진 | 벽 13 + 문 1 청사진 배치, 일꾼이 건설 시작 |
| 7 | 농장 도구 | 구역→경작, 경작 도구 활성 |
| 8 | 농사 지역 | 6셀 드래그 → 초록 경작 구역 마커 |
| 9 | 첫 사이클 완성 | 벽 둘린 방(지붕 음영)+저장구역+농장, 일꾼 자율 건설 완료 |

검증: structureCount(wall)=13 PASS, growZoneCells=7 PASS, OVERALL PASS.
재현 시나리오: `_walkthrough.json` (G:/ai). 이 흐름은 매 커밋 게이트의
`_showcase-human-rhythm.json` 과 동일 입력 경로로, 회귀 시 즉시 적발된다.

## 기본 사이클 = 한 호흡

저장공간 설정 → 집짓기(벽·문·지붕) → 농사 지역 → 일꾼 자율 수행(벌목·운반·건설·
파종) → 밤이 되면 침대에서 취침(누움 포즈) → 식사·연구 → 습격 대응.  각 단계가
플레이어 클릭으로 시작되고 콜로니스트가 utility-AI 로 이어받는다.
