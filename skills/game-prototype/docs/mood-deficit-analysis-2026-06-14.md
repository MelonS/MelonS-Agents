# 무드 적자 특성화 — D-A 결정 근거 (2026-06-14 자율세션)

운영자 복귀 결정 큐 1순위(**D-A 무드 모델 갈림길**)를 위한 데이터.  무인 redesign 은
금지(모델 선택은 운영자 영역)이나, 결정을 돕는 **정량 특성화**는 안전하게 제공.

출처: human-rhythm 4게임일 소크 `_repro_run__showcase-human-rhythm.log` 의
[SleepMon](5초 주기 sleep/mood) 634샘플 + [Mood] 붕괴 이벤트.

## 무드 궤적 (민지/서연/지훈, 0→끝 6분위)
- 민지: 87 → 73 → 57 → 43 → 40 → 60   (min 16, max 88)
- 서연: 74 → 60 → 47 → 33 → 29 → 41   (min 17, max 74)
- 지훈: 79 → 65 → 44 → 33 → 29 → 50   (min **2**, max 79)

## 핵심 진단 (노이즈 아님 = 구조적 적자)
1. **주간 단조 하락 → 야간 부분 회복**의 톱니인데, 저점이 회복점보다 낮아 **순 하방
   드리프트**.  3인 모두 하루 중반~후반에 mood 30→20 권으로 내려앉음.
2. **전원 mood<20(붕괴 임계) 진입**: 민지 9 / 서연 11 / 지훈 12 샘플.  지훈은 **min 2**
   (심각).  <30 체류: 23 / 55 / 40 샘플 = 저무드 장기 노출.
3. [Mood] 붕괴 이벤트: 소크당 1~3건(서연 m19·지훈 m18·민지 m17), 전부 카타르시스
   복귀(death-spiral 은 아직 없음 — 적응계수/관전모드가 막아줌).

## 적자 구조 (코드 근거, 변경 안 함)
- 양성 thought 는 배선됨: 고급침대 +6 / 침대 +3 / 푹잠 / 식사류 / 식탁 +N.
- 음성 압력: 수면부족·허기·어둠속활동·작업 등 누적.  **양성 회복 < 주간 음성 누적**이라
  순 적자.  즉 미배선 버그가 아니라 **밸런스(회복/드레인/임계) 튜닝 = 모델 선택**.

## 운영자 선택지 프레이밍 (D-A~D-G, 택1 — 무인 적용 금지)
- **회복 강화**: 야간 수면 mood 보너스 ↑ / 양성 thought 지속·크기 ↑ / 식사·여가 보너스 ↑.
- **드레인 완화**: 수면부족·어둠 등 음성 thought 크기·발생 ↓.
- **임계/완충**: 붕괴 임계 20→낮춤 또는 회복 히스테리시스(붕괴 후 면역창).
- **여가 도입**(위키 phase2 [없음]): recreation/joy need + 휴식으로 mood 부양(가장 정본적).
> 권고 관점: 데이터상 "주간 순 적자"가 본질 → **회복강화 또는 여가도입**이 근본,
>  임계조정은 증상완화.  단 어느 쪽이든 다회-소크 회귀검증 동반 필요(붕괴 0~3 노이즈).

[SleepMon] 계기 + _sleepcurve + 소크 시나리오.  D-option 적용 후 같은 소크로 mood
저점·붕괴수 before/after 비교 가능.
