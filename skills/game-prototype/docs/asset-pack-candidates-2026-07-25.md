### 🥇 1순위: Kenmi **Cute Fantasy 전체 번들** + 야생동물 보충 — 총 **$17.50~$25**
- 구성: Cute Fantasy 번들 $17.50 (메인 RPG + Characters + Dungeon + Desert + Volcano + UI 등 10팩) + Top-Down Hunt Animals(무료) 또는 ToffeeCraft 늑대 $1.80 + Sanctumpixel 사슴 $4.20
- 왜: **단일 스타일로 필요 커버리지 9개 중 8개를 한 번에** 해결하는 유일한 후보. 특히 **플레이어 제너레이터**(의상·헤어 조합)가 콜로니심의 "폰 다양화" 요구와 정확히 맞물림. 농장동물 11종·작물 22종·인테리어·UI까지 있어 조합 리스크(스타일 충돌)가 최소. 16px→PPU 32 x2 정수 스케일 무손실.
- 리스크: 야생동물만 외부 보충 → 팔레트 보정 1회 필요. '판타지 큐트'라 개척 콜로니의 소박함보단 살짝 화사함.

- 리스크: Kenmi 대비 적·전투 계열 빈약(우리 게임에 습격이 있다면 보충 필요). 야생동물 없음.

### 🥉 3순위 (제로코스트 플랜B): **Sunnyside World + Ninja Adventure(CC0) + Hunt Animals** — 총 **$0** (후원 권장)

### 실무 권고
1. **기본안: 1순위(Kenmi 번들)로 집행** — $25 이하로 커버리지·통일감·폰 커스텀을 동시 확보. 상업·해커톤·포트폴리오 모두 라이선스 클리어(리셀 금지만 준수).

4. Unity AS Cozy 번들($29.99)은 물량은 최대지만 테마 혼재로 큐레이션 비용이 커서 해커톤 타임라인엔 비권장 — 출시 확장 단계의 2차 후보로 유지.
