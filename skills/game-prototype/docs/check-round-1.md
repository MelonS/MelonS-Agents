## ① 림 작업마비 / 벌목↔떠도는중 번갈이 (오늘 근본수정 bb588fa)

**조작**: 새 게임 → 림 선택 → 나무 우클릭 → "벌목" 클릭. 그리고 별도로 5분쯤 그냥 방치.

**예상**: 림이 나무 옆 칸까지 걸어가 베고, 나무가 쓰러져 통나무 더미가 떨어짐.
방치 중에도 "벌목↔떠도는중" 같은 1초 단위 번갈이(작업마비)가 없어야 함.
(원인이 "졸리면 매 1.5초 작업 강제해제 → 침대 없어 잠도 못 자고 무한루프"였음 — 수정됨.)

**harness 증거**: `p0-remote-chop` 우클릭→도달(1.94칸)→나무 45→44 (7초) PASS.

**+오늘 추가 fix**: 4회 반복 중 1회에서 "림이 나무에서 2칸 떨어진 채 허공 벌목"을 잡았음 —
림이 작업칸 **경계를 밟는 순간** 도착 처리돼 그 자리에 얼어붙던 버그 (간헐 — "어쩔 땐 되고
어쩔 땐 안 되고"의 정체로 추정).  이제 칸 중심까지 걸어간 뒤 작업.  벌목뿐 아니라 채광·건설·
요리·채집·수확·운반·재배 전부 같은 수정 적용.

## ② 수면·식량 게이지 줄어드는 속도 체감

**조작**: 림 선택 → info 탭에서 수면/식량 게이지를 게임 속도 1x 로 잠시 관찰.

**예상**: 둘 다 눈에 띄게 줄어듦. 수면은 저녁 무렵 탈진 페이스(설정 0.12 실측 정합),
식량은 림이 배고프면(40 미만) 알아서 먹어서 50~60대 사이클.

**질문**: 줄어드는 속도가 체감상 적당한가? (너무 빠름 / 적당 / 너무 느림)

## ③ 통나무 더미 내구도 — 속도 결정 필요

**조작**: 나무 하나 벤 뒤 떨어진 통나무 더미를 **운반하지 말고** 방치하고 배속(4x)으로 관찰.
비교로, 저장구역을 만들어 운반된 목재도 확인.

**예상**: 옥외 더미는 점점 옅어지다 사라짐. 저장구역 안 더미는 보존(의도된 동작 —
"운반 안 한 자원만 썩는다", RimWorld 동일).

**harness 증거**: `p1-wood-durability` 내구도 98→0 페이드 소멸 PASS (스크린샷 3장).

**질문**: 현재 옥외 더미 수명이 **게임시간 반나절**임 (코드의 낡은 "24초=1일" 가정 때문,
의도였던 10게임일의 1/41). 어느 쪽으로 맞출까?
- (a) 지금처럼 반나절 — 운반 압박 강함, 닳는 게 눈에 확 보임
- (b) RimWorld식 수 게임일 — 느긋함, 대신 닳는 건 며칠 지나야 보임
- (c) 중간 (예: 1~2게임일)

## ④ 기분(mood) — "좋은 thought만" 미재현 보고

**조작**: 림 info 의 기분 탭 관찰. 잠 못 자게 두거나(침대 없음) 부상당하면 부정 thought 확인.

**harness 증거**: 결정론·자연 플레이 양쪽에서 부정 thought(-) 와 mood 하강 작동 확인
(`p1-mood-negative-direct`: 수면 부족 -3 즉시 반영 / `p1-mood-negative`: 자연 플레이서 mood 74→65→44 하강).
참고: 식량이 충분하면 림이 알아서 먹으므로 "배부름"(+) 만 보이는 건 **잘 돌아가는 콜로니의 정상 모습**.

**질문 1**: 여전히 "기분이 안 나빠진다" 체감이면, 그때 상황(식량 바닥? 침대 있음? 부상?)을 알려달라.

**질문 2 (역방향)**: harness 실측상 mood 가 첫날 저녁에 이미 36 까지 내려감 (시작 ~75, 정신붕괴 임계 20).
침대·실내 등 회복 수단이 생기기 전까진 하강 일변도 — **하강 속도가 너무 빠르지 않은지** 같이 봐달라.

**질문 3 (오늘 fix — 폭풍)**: 20분 longplay 에서 **폭풍 1회에 림 전원 동시 정신붕괴**를 발굴해
수정했음 (숨은 직접 드레인 -3/초×60초=-180 제거 → '야외 폭풍' thought -6 로 일원화).
- 폭풍 노출 페널티 -6 (잠깐 우울) 체감 적당한가?
- 현재 피난처 판정은 **바닥타일 위**뿐 — 벽으로 둘러싸도 바닥을 안 깔면 야외 취급. 이대로 둘까,
  지붕/실내 개념(큰 작업)으로 갈까?
