## Phase 1 — 7일 스프린트 스캐폴드 (2026-05-26)

`game-dev-agent` + `game-prototype` 스킬을 스캐폴드하고, Day 1~7을 하루만에 압축 구현.
초기엔 "하루 = 한 기능, 매일 실행 가능한 .exe"라는 daily-shippable 원칙으로 진행.

- **Day 1** Unity 씬 + 스크립트 + .exe 빌드 성공
- **Day 2** pawn 이동 + needs(식량/수면/기분) UI
- **Day 3** 나무 + 벌목 액션 + 목재 카운터
- **Day 4** 3 colonist + 유틸리티 AI 자동 벌목
- **Day 5** AI Director 런타임 이벤트 + 이벤트 로그 UI
- **Day 6** 저장/불러오기 + 절차적 SFX + AudioBank
- **Day 7** 7일 스프린트 완료 (포트폴리오 문서)

핵심 기반: Unity batchmode 통합 파이프라인(`agent.py integrate --method scenes|build`),
절차적 sprite/SFX(저작권 안전), self-verify 루프.

## Phase 2 — 바닐라 시스템 대폭발 (2026-05-27, 168커밋)

하루만에 Day 8 → Day 80+ 와 stretch 기능까지. 바닐라 콜로니심 코어를 대거 구현.

- **시간/카메라**: 카메라 팬·줌, 시간 배속, **낮/밤 사이클 + GameClock**, 야간 NightOverlay
- **니즈/생존**: 밤 수면, food 시스템, regen, **meal 우선 섭취**(mood 보너스)
- **전투/스킬**: PawnSkills 4종(채집/벌목/건축/전투) + XP/레벨, **징집(Drafted) 수동제어**, 활/화살 원거리, PawnHealth 부위별, mood break
- **세계**: 날씨(폭풍), 동물(사슴 5) + **자동 사냥**, 늑대 포식자, 지형 다양성(흙/물/바위), 40x40 맵
- **건축**: 벽/바닥/문 클릭 배치(자재 소비), **화덕 + PawnCook 자동 조리**
- **연구**: ResearchBench + 트리 + UI
- **성격/정착**: PawnTraits 8종, 시작 정착지 + 농장 + stockpile 미리 배치
- **농경**: crop 성장 + 우클릭 수확
- **연출**: Storyteller arcs 3종 + threat tier + 15 이벤트, 튜토리얼 오버레이(한글 팁 9), BGM 절차적 루프
- **한글화**: UI/이벤트 전체 + 폰트 폴백 체인
- **stretch**: 상인 caravan + 거래, 동물 길들이기 MVP
- 이 시점 림 바닐라 커버리지 ~85% (자체 평가)

## 누적된 핵심 교훈 (메모리화)

- **거짓 검증 금지**: stale 빌드(날짜 스탬프 폴더 + exe vs Assembly-CSharp.dll), 우회 시뮬 PASS 등. 항상 동적 최신 빌드 + 운영자 실제 경로로 검증.
- **추측 금지·관찰 우선**: 버그는 실제 빌드/프레임으로 재현·관찰 후 수정. (폴리싱 감사도 거짓 항목을 코드로 걸러냄)
- **바닐라 콜로니심 기준**: 임의 밸런스/설계 금지, 위키 참조.
- **대충 금지**: 표준 정공법으로 제대로 + 직접 검증.
- **연속 폴리싱**: 명시 큐가 끝나도 자가발견(feature-audit) + 파이프라인 감사로 이슈를 스스로 찾아 계속.
