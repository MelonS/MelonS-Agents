## 면접 직전 체크리스트 (5분 전)

1. **크롬으로 연다.** Safari 는 Unity 가 공식 지원 대상이 아니다 — 크롬/엣지 권장.
2. **미리 로드해두고 탭을 켜둔다.** 빌드가 약 19MB라 현장 와이파이가 느리면
   로딩에 시간이 걸린다. 면접 시작 전에 열어서 **메뉴 화면까지 띄워놓을 것.**
3. 로딩이 끝나면 우하단 **전체화면 버튼**(↗)으로 키운다.
4. 소리가 필요하면 볼륨 확인 — 브라우저는 첫 클릭 전까지 오디오를 막는다.
   '게임 시작'을 누르는 순간부터 나온다.
5. 배터리·절전 모드 해제 (WebGL 은 GPU 를 쓴다).

> **오프라인 대비**: 와이파이가 아예 안 되면 URL 도 안 열린다.
> 백업 자산은 아래 "백업 플랜" 절 참조.

## 5분 시연 동선

각 단계에 **무엇을 보여주는가**를 붙였다. 시간이 없으면 ①②④만 해도 된다.

### ① 시작 — "간접 조작 콜로니 심입니다" (30초)

`게임 시작` 클릭 → 맵 진입. **게임은 일시정지로 시작한다** (의도된 설계).

> 말할 것: "탑다운 콜로니 시뮬레이션입니다. 유닛을 직접 조종하는 게 아니라
> 일감을 지정하면 콜로니스트들이 우선순위에 따라 알아서 판단해서 움직입니다."

> **건축 시연 확인됨 (2026-07-27)**: 브라우저에서 손으로 검증했다 —
> 건축 → 구조 → 목재 벽 → 맵 클릭 시 청사진이 생기고 토스트가 뜬다.  대본대로 진행 가능.
>
> **야간 작업 반영 (2026-07-27 04:30)**: 시작 시 저장구역이 미리 깔려 있어, 배속을 올리면
> **30초 안에 목재 0→300 · 식량 0→60 · 정착지 가치 90→396** 이 눈앞에서 오른다.
> 그러니 ①에서 바로 `3x` 를 눌러 숫자가 오르는 걸 보여주고 시작하는 게 좋다.
> 전체 야간 변경 내역: [`overnight-2026-07-27.md`](overnight-2026-07-27.md)

### ② 일감 지정 → 자율 수행 (90초) ★핵심

1. 콜로니스트 하나를 **좌클릭**해서 선택 (상단 초상화 클릭도 됨)
2. 나무를 **우클릭** → 벌목 지정
3. 하단 `건축` → `구조` → `목재 벽` 을 골라 맵에 **4칸 배치**
4. `문` 하나, `가구` → `침대`, `생산` → `화덕` 배치
5. `3x` 배속

> 말할 것: "지금 제가 한 건 '무엇을 할지' 지정한 것뿐입니다. 누가 언제 어떤
> 순서로 할지는 각 콜로니스트의 작업 우선순위·스킬·현재 니즈가 결정합니다."
>
> **이 단계가 데모의 심장이다.** 지정을 안 하면 자원 카운터가 0에 머물러서
> "아무 일도 안 일어나는 게임"으로 보인다. 반드시 무언가를 지정하고 배속을 올릴 것.

### ③ 시스템 깊이 (60초)

하단 `작업` 클릭 → **작업 우선순위 그리드** (콜로니스트 3명 × 직종 9종, 0~4단계).

> 말할 것: "장르 표준인 작업 우선순위 그리드입니다. 이 숫자가 AI 의 행동 선택에
> 직접 들어갑니다." — `일정`(24시간 스케줄), `연구`(기술 트리)도 같은 줄에 있다.

### ④ 살아있는 콜로니 (60초)

`6x` 배속으로 하루를 돌린다. 시간대에 따라 화면 색조가 바뀌고(전역 컬러 그레이딩),
콜로니스트가 먹고·자고·일하고, 건설이 진행되고, 동물이 돌아다닌다.

> 말할 것: "1게임일이 실시간 1,000초입니다. 니즈·무드·스케줄이 전부 시뮬레이션
> 되고 있고, AI 스토리텔러가 정착지 가치에 따라 위협 이벤트를 띄웁니다."

### ⑤ 마무리 — 만든 방식 (60초)

> 말할 것: "이건 AI 에이전트 파이프라인으로 만들었습니다. 기획·아트·프로그래밍·QA 를
> 역할별 에이전트로 나누고, 아트는 별도 TA 에이전트가 스크린샷을 실제로 보고
> 채점하는 게이트를 거칩니다. 커밋마다 16종 재현 시나리오가 자동으로 돕니다."

## 백업 플랜

시연은 **URL 1개 + 로컬 사본 1개** 이중화를 권한다.

### 백업 A — 로컬 실행 (와이파이 불통 대비)

맥북에 `pawnsim-webgl.zip` 을 미리 받아둔다. 압축을 풀고 그 폴더에서:

```bash
cd ~/Downloads/pawnsim-webgl
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` — 맥 기본 python3 로 동작한다.
(WebGL 은 `file://` 로 열면 안 된다. 반드시 http 서버 경유.)

### 백업 B — 스크린샷

`docs/demo-shots/` 에 인게임 캡처를 커밋해뒀다. 최악의 경우 이것만으로 설명 가능.

## 알려진 함정

- **게임이 일시정지로 시작한다** — 시작 직후 화면이 안 움직여도 정상. `1x`/`3x` 를 눌러야 흐른다.
- **아무것도 지정 안 하면 자원이 0에서 안 움직인다** — 바닥에 목재 300이 있어도
  저장구역·일감이 없으면 콜로니스트가 나르지 않는다. ②단계를 건너뛰지 말 것.
- **키보드 단축키보다 하단 버튼을 쓸 것** — WebGL 은 캔버스 포커스를 잃으면 키 입력을
  먹는다. 마우스 조작이 안전하다. (F1 작업 / F8 건축 / R 징집 은 포커스가 있을 때만.)
- **첫 클릭 전 오디오 없음** — 브라우저 정책이며 버그가 아니다.
