# 사람 플레이 vs 자동플레이 갭 — 웹 리서치 (2026-06-12)

운영자 피드백: "프로토타입 플레이 영상을 보고 있으면 사람이 플레이하는 것과 많이 달라."
→ 레퍼런스(콜로니심 장르 표준) 위키·가이드·플레이 영상 관행을 웹 리서치로 교차 확인한 결과.
핵심 주장(시작 시 일시정지, 수동 우선순위, 점진 확장)은 각 3개 이상 독립 소스에서 일치.

> 내부 문서 — 출처 IP명 그대로 표기. 공개 README에는 장르명으로만 추상화할 것.

## 핵심 진단

사람 플레이의 본질은 4박자:

1. **정지-계획-실행 사이클** — 명령은 일시정지에서, 노동 구간은 배속으로.
2. **일차별 점진 확장** — 첫날 목표는 지붕+침대+비축뿐. 농사는 5x5 한 칸, 채광은 며칠 뒤.
3. **이벤트 반응형 개입** — 레터 뜨면 감속·카메라 점프·징집/치료 마이크로 개입.
4. **관심 대상을 쫓는 카메라** — 줌인/줌아웃 끊임없이, 림 팔로우.

우리 자동플레이는 4가지 모두 정반대(0초 실시간 일괄 지정 · 전부 동시 착수 · 무개입 · 고정 줌)
→ "사람 같지 않음"이 즉시 보임.

## 차이점 14개 (사람은 X / 자동플레이는 Y → 제안)

### A. 첫날 순서/리듬
1. **시작=일시정지부터.** 사람은 착륙 즉시 정지하고 맵을 둘러본 뒤 첫 명령. 위키가 대문자로
   "PAUSE THE GAME!" / 우리는 0초부터 실시간 일괄 투하.
   — 출처: 콜로니심 장르 위키 bigbossbattle.com/first-days-reference-sim
   → 시나리오 시작 5~10초 "정지+카메라 패닝(맵 서베이)" 페이즈 후 첫 명령.
2. **첫 행동은 정리: 금지 해제+무기 장착.** 사람은 물자 unforbid→장비 픽업→재정지·계획 /
   우리는 바로 구역 지정. — Quickstart_Guides, Basics, steam 745100743
   → 페이즈 0에 "물자 회수/장비 픽업" 추가 (저장구역 지정보다 먼저).
3. **입지 정찰 후 건설.** 사람은 징집해 방어 지형 찾고 나서 짓는다 / 우리는 착륙점에 즉시.
   — bigbossbattle, Basics(Base location)
   → 시작 직후 림 1명 "정찰 워크"(맵 가장자리 2~3곳) + 카메라 팔로우.
4. **Work 탭 수동 우선순위를 첫날 세팅.** Firefight/Patient/Bed Rest/Basic=1 전원,
   Doctor/Cook/Construct/Grow는 최고 스킬자만 / 우리는 기본값 방치.
   — Quickstart_Guides, steam 2070888684
   → 페이즈 1에 Work 탭 열고 우선순위 변경하는 UI 시퀀스 노출.

### B. 페이싱
5. **정지·배속(1x/3x/6x) 상시 토글.** 계획=정지, 노동=3x/6x, 사건=1x /
   우리는 단일 속도 고정·정지 0회. — thegamer.com 14 beginner tips, wiki Controls
   → "명령 발행 시 0.5~2초 정지→발행→재생, 무사건 구간 3x" 속도 상태머신.
6. **밤=빨리감기, 자는 림 안 깨움**(disturbed sleep 회피). 밤은 니즈 점검 타임 /
   우리는 밤낮 동일. — Quickstart(Your first night)
   → 야간 배속+명령 금지, 새벽에 명령 묶음 발행.
7. **이벤트 레터 = 강제 감속.** 본가는 위협 이벤트 시 엔진이 감속·배속 잠금 /
   우리는 무반영. — steam 1419593453 (No Forced Slowdown 모드의 존재가 증거)
   → **PawnSim 엔진 기능**: 레터 도착 → 1x 강제 + 카메라 점프. (게임 기능, 시나리오 아님)

### C. 카메라
8. **줌인/줌아웃 상시.** 전략=줌아웃, 구경/방송=줌인. Camera+ 모드 수요가 증거 /
   우리는 고정 줌. — steam 867467808, github pardeike/CameraPlus
   → 소크용 카메라 디렉터: 기본 중간 줌, 이벤트 줌인, 페이즈 전환 줌아웃 오버뷰.
9. **림 팔로우 관찰.** Follow Cam 모드가 따로 있을 정도 / 우리는 추적 0회.
   — steam 3724388977
   → "가장 흥미로운 림(전투>치료>건설) 30초 팔로우" 로테이션.

### D. 점진성
10. **첫날 목표 3개뿐: 지붕+침대+비축. 농사 5x5, 채광은 며칠 차.** /
    우리는 저장+경작+벌목+채광+건설 전부 0일차 일괄. — Quickstart(Your first day), steam 745100743
    → 일차별 페이즈: D1 비축+막사+5x5 농지, D2 벌목 확대+채집, D3+ 채광/방어.
11. **막사 먼저, 침실은 1주차 이후.** 9x9 공용 1실 시작, 확장은 수확/자원 보고 단계적 /
    우리는 최종 설계도 일괄 지정. — theguidehall.com early game, jeu.video 가이드
    → 건설 큐를 완공 트리거 체인으로: 막사 완공→식량창고→첫 수확→침실.
12. **수확 전 갭은 채집/사냥 임기응변.** 첫날 체크리스트에 "베리 수확 지정" 포함 /
    우리는 경작 후 무대응. — Quickstart(The next few days), steam 745100743
    → 식량 임계치 미만 시 야생 베리 수확/사냥 지정 반응 룰 1개.

### E. 마이크로 개입
13. **Prioritize 우클릭 + 징집이 상시 개입 수단.** 위협=징집·엄폐, 출혈=의사 징집 현장 치료 /
    우리는 지정 후 개입 0회. — wiki Prioritize/Orders/Defense_tactics
    → 반응 룰 3종: 위협 스폰→전원 징집·엄폐 / 부상→치료 우선 / 핵심 건물 미완→prioritize.

### F. 관전 포인트
14. **사람 영상의 재미 = 위기 대응 드라마 + 림 개인 서사.** 본가는 "스토리 제너레이터" 설계 /
    우리 영상은 위기도 캐릭터도 없는 균일 노동 타임랩스 — "다르게 보이는" 근본 원인.
    — en.wikipedia.org/wiki/the reference sim, GDC 1024232, gamedeveloper.com procedural storytelling
    → 소크에 의도적 위기 1~2개(소형 습격/화재) 스케줄 + 7·8·13번 연결 = "사건→반응" 루프를 영상에.
