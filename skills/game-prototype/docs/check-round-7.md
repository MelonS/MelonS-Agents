### 1. 바위 지형 "QR 격자" 해체  `[표현]`
- **증상**: 스폰 오버뷰 우상단의 회색 바위 밭이 셀마다 똑같은 고대비 다이아몬드
  무늬가 박혀 격자(체커보드)처럼 보였다 — 오버뷰에서 제일 튀는 "싸구려" 신호.
  잔디·흙은 TOP-1에서 해소됐는데 **바위만 누락**이었다.
- **원인**: 바위는 PathGrid 가 타일 레퍼런스 동일성으로 통행 차단을 판정 → 변형
  추가 불가.  그래서 `rock_a` 한 장이 전 바위 셀에 반복되는데, 생성기가 큰 고대비
  명/암 패치를 셀마다 같은 자리에 깔아 격자가 됐다.
- **수정**: `rock_tile()` 을 잔디/흙과 동일 규율(1px 테두리 + 작은 저대비 클러스터
  전면 산란 + 밝은 점 최소화)로 재작성.  휘도 stdev 14.2 → 5.1 (잔디 5.9·흙 6.2 동급).
- **확인**: 게임 시작 → 우상단 바위 밭이 잔잔한 돌바닥으로 보이고 격자가 없으면 OK.

### 2. 건축 ▸ 구역 "영역 제거" 버튼 정리  `[버그]`
- **증상**: 건축(F8) → 구역 메뉴에서 "저장/폐기 영역 제거"/"지붕 영역 제거" 버튼의
  라벨이 칸을 넘쳐 **잔디(월드) 위로 글자가 떠** 판독 불가였고, ✕ 아이콘이 순적색
  살몬이라 "오류/깨짐"처럼 보였다.
- **수정**: 셀엔 축약명("저장 제거" 등)·툴팁엔 전체 설명 / 텍스트 Wrap 안전망(옆으로
  월드 침범 차단) / ✕ 살몬레드 → 차분한 테라코타(도구로 읽히게).
- **확인**: F8 → 구역 클릭 → 제거 버튼 라벨이 칸 안에 담기고 ✕가 안 튀면 OK.
