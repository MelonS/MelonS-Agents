# 기본 4축 검수 루브릭 — 집·농사·벌목·채광 (운영자 2026-06-12 "기본부터")

> 용도: 격리 채점(grader) 서브에이전트가 **작업 맥락 없이** 이 기준표 + 증거(샷/로그)만으로
> 채점한다 (Ralph-loop 패턴 — 작업자 자기채점 편향 차단).  각 항목은 P(통과)/F(실패)/
> U(증거 불충분)로 판정하고, F/U 는 반드시 증거(파일명·좌표·로그 라인)를 인용한다.
> **전제 검증이 우선**: 셋업 스텝(클릭) 중 하나라도 FAIL 이면 해당 축은 자동 U — 깨진
> 전제 위의 측정은 무효.

## 0. 전제 (모든 축 공통)

- [ ] P0-1. 시나리오 로그에 `clickui: FAIL` 0건 (셋업 클릭 전부 PASS)
- [ ] P0-2. `OVERALL: PASS` + timeout 미발생

## 1. 집 (벽·문·지붕)

- [ ] H-1 **기능**: 벽 12칸 지정 → 3게임일 내 전부 완공 (로그 `[Builder] 건설 완료 (Wall...)` ≥12 또는 최종 샷에서 ㅁ자 폐합)
- [ ] H-2 **기능**: 문 1칸 완공, 벽 라인에 끼워짐
- [ ] H-3 **기능**: 지붕 6칸 지정 → BUILT 셰이드(진한 슬레이트 오버레이)가 방 내부에 가시
- [ ] H-4 **시각**: 벽이 '입체 블록'으로 읽힘 — 밝은 윗면(cap)과 어두운 전면이 구분되고, '바닥에 깐 판자'로 오독되지 않음
- [ ] H-5 **시각**: 문이 벽과 한눈에 구분됨 (문짝/손잡이 식별 가능)
- [ ] H-6 **시각**: 벽-벽 연결부에 어색한 부유 무늬(사다리 모양 seam 등) 없음

## 2. 농사

- [ ] F-1 **기능**: 경작 6칸 지정 → 림이 파종 (샷에서 작물 새싹 ≥4칸 또는 로그 파종 흔적)
- [ ] F-2 **기능**: 작물 성장 단계 변화 관측 (새싹→성장 스프라이트, day별 샷 비교)
- [ ] F-3 **기능**: 익은 작물 자동 수확 (식량 카운터 증가 또는 수확 로그)
- [ ] F-4 **기능(영구 구역)**: 수확된 칸에 **재파종** 발생 — 마지막 샷에서 수확된 자리에 새 새싹
- [ ] F-5 **시각**: 경작 마커(녹색 틴트)가 **빈 지정 칸**에 보임.  (작물이 자라는 칸은 영구구역 설계상 마커를 숨긴다 — 수확 후 재파종 대기 칸에서 복귀하면 P)

## 3. 벌목

- [ ] C-1 **기능**: 지정한 나무 ≥3그루가 3게임일 내 벌목됨 (해당 좌표 나무 소멸 + 그루터기/통나무)
- [ ] C-2 **기능**: 통나무 더미가 저장고로 운반되거나 목재 카운터 증가
- [ ] C-3 **시각**: 벌목 지정 마커가 지정 직후 샷에서 식별 가능

## 4. 채광

- [ ] M-1 **기능**: 광맥 클릭이 실제 광맥 셀에 명중했는가 (worldclick `at=StoneVein...` — 빗나갔으면 U, 좌표 보정 필요)
- [ ] M-2 **기능**: 마킹된 광맥이 채광됨 (광맥 소멸 + 석재 청크 드롭 또는 석재 카운터 증가)
- [ ] M-3 **시각**: 광맥이 '암반 속 광물'로 읽힘 — '검은 액자' 오독 없음

## 5. 떠돌기 (보조 관찰)

- [ ] W-1: 일감(지정)이 남아 있는 동안 "떠도는중" 상태의 림이 과반이 아님 (중간 샷들에서 림 작업 상태 관찰)

## 판정 규칙

- 축별 판정: 기능 항목 전부 P → 축 PASS. 하나라도 F → 축 FAIL + 항목별 피드백.
- 시각 항목 F 는 축 FAIL 은 아니되 별도 '시각 백로그'로 분리 보고.
- grader 는 수정 제안을 하지 않는다 — 판정과 증거 인용만. (수정은 작업자 루프 몫.)


## 6. 풀 운영 소크 루브릭 (8게임일 — _soak_full.json 계열)

전제(P0-1/P0-2) 동일 적용.  추가로 셋업 내장 어서션(chopDesignations/mineMarks/
growZoneCells/blueprintCount/roofCells) 전부 PASS 여야 본 절 채점 가능.

- [ ] S-1 **생존**: GameOver 0건 (로그 grep) — 원년 림 3명 중 ≥2 생존
- [ ] S-2 **집**: 종반 어서션 bed≥3/stove≥1/bench≥1 PASS + 최종 샷에서 ㅁ자 집+지붕 유지
- [ ] S-3 **농사 루프**: day별 샷에서 작물 성장→수확→재파종 사이클 ≥1회 관측
  (같은 칸이 익음→빈 마커→새싹으로 변하는 시퀀스), 종반 growZoneCells=6 유지
- [ ] S-4 **벌목/채광 경제**: 목재·석재 카운터가 0 고정이 아님 (적립·소비 변동 관측)
- [ ] S-5 **연구**: 연구대 완공 후 포인트 진행 >0 (HUD "원시 활 N/100" N>0 또는 완료 로그)
- [ ] S-6 **떠돌기**: 중간 샷 3장 이상에서 림 과반이 작업/이동 중 (전원 정지 들판 배회가
  지배 상태가 아님)
- [ ] S-7 **식량 경제**: 아사 사망 ≤1 (합류자 포함), 식사 카운터가 한 번이라도 >0
