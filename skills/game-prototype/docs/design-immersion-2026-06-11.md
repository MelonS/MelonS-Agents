# 몰입감 디자인 트랙 — 2026-06-11

운영자: "디자인이 너무 별로야. 몰입감이 떨어져. 디자인을 획기적으로 개선할 방법 없어?"

진단: 스프라이트 해상도가 문제가 아니라 **화면이 정적**인 게 문제다.
림은 미끄러지듯 평행이동(애니메이션 0), 그림자 없음(공중부양 느낌), 작업 피드백이
FloatingText 뿐(타격감 0), 밤낮은 단색 틴트 뿐. 레퍼런스 콜로니심은 저해상도 그림이어도
걷기 바운스 + 그림자 + 파티클 + 광원만으로 "살아있는" 화면을 만든다.

원칙: 새 아트 자산 0 으로 가능한 것부터 (전부 절차적/코드). 기능 추가 아님 — 표현 레이어만.
머니 파이어월: 외부 자산은 CC0 만, 그것도 D5 비교 목업 후 운영자 결정.

## 배치 (각각 독립 커밋, repro_all 게이트)

- **D1 blob 그림자** — 부드러운 타원 스프라이트 1장(절차 생성) 을 림/나무/바위/건물/동물
  발밑에. alpha ~0.25, 엔티티 폭 비례. 가장 싸고 효과 최대(접지감).
- **D2 걷기/작업 모션** — 이동 중 y 사인 바운스(~0.04, 6Hz) + 진행방향 좌우 flip +
  살짝 기울기(3°). 작업 중(벌목/채광) 타깃 방향으로 momentum 펄스. 스프라이트 교체 없이
  transform 만 — 끊김/추가 아트 0.
- **D3 파티클** — 벌목 나무칩, 채광 돌파편, 발걸음 먼지(이동 중 0.5s 간격), 모닥불
  불티+연기, 폭풍 빗방울 스플래시. Unity ParticleSystem, 머티리얼은 기본 sprite.
- **D4 빛/대기** — 새벽/황혼 컬러 그레이딩 곡선(현 단색 틴트 → 2색 그라데이션),
  밤 모닥불/램프 halo 강화, vignette 런타임 미로드(#9.0) 해결 겸 통합.
- **D5 스프라이트 품질 (운영자 결정 게이트)** — CC0 팩(Kenney 등) vs 현행 자체 픽셀
  비교 목업 스크린샷 제시 후 결정. 전면 교체는 D1-D4 효과 확인 뒤에만.
