# 아트 스타일 가이드 v3 — 페인털리 64px (정본)

**지위**: 모든 생성·반입 아트의 상위 기준. 이 문서를 통과하지 못한 에셋은 반입 금지.
운영자 방향(2026-07-25): "림월드식으로 가자 · 셀당 64 · **톤 유지 신경쓰면서**".

## 1. 기본 규격
- **밀도**: 셀당 64px (PPU 64). 나무 64×96(1×1.5칸), 1칸 오브젝트 64×64,
  광맥/더미 64×64, 림 64×96 예정.
- **스타일**: 페인털리 소프트 셰이딩 + 은은한 다크 아웃라인. 픽셀 그리드 불요.
  "detailed miniature illustration" 결.
- **조명**: 전 에셋 좌상단 광원 고정 (top-left). 위반 = 반입 불가.
- **각도**: 톱다운 3/4 (위에서 내려보되 측면이 보이는 각). 순수 조감(버드아이) 금지
  — spruce 1차에서 톱뷰 2장 탈락한 사유.

## 2. 톤 팔레트 (들쭉날쭉 방지 — 핵심)
- **채도 상한**: HSV S ≤ 0.75 (단풍 등 포인트 컬러만 0.85 허용, 화면당 소량).
- **명도 범위**: V 0.15~0.92. 순백·순흑 금지.
- **기준 램프**: 잔디 #607446 계열 / 흙 #8C5C36 계열 / 목재 #BC8A58~#5C3C24 /
  돌 #9AA0A8 계열. 신규 에셋의 지배색은 이 램프에서 ±15° 색상 이내.
- **하모나이즈 패스(의무)**: 반입 전 후처리에서 채도 클램프 + 화이트밸런스를
  기준 램프에 소프트 매칭. (`scratchpad` 파이프라인 → 추후 scripts/art_v3_process.py 로 정식화)

## 3. 생성 프롬프트 표준 템플릿
```
{대상 묘사}, top-down view game sprite for a colony simulation game,
painterly soft shading with subtle dark outline, muted natural earthy palette,
soft volumetric light from top-left, isolated on pure white background,
nothing else in frame, no ground plane, no cast shadow, centered,
detailed miniature illustration
```
- 금지어: "floating"(섬으로 그림), "pixel"(픽셀 폐기), 스타일 형용사 남발.
- 시드 3~6안 생성 → 큐레이션. FLUX schnell 스텝 8.

## 4. 큐레이션 합격 기준 (전 항목 충족)
1. 톤: §2 팔레트·채도 범위 내 (히스토그램 확인)
2. 조명: 좌상 광원 일치
3. 각도: 톱다운 3/4
4. 바닥 요소 없음 (타원 그림자·흙받침 → 후처리 제거 가능하면 조건부 합격)
5. 실루엣: 게임 크기(1x)에서 오브젝트 종류가 즉시 식별
6. 기존 반입분과 나란히 두었을 때 이질감 없음 (컨택트시트 비교 의무)

## 5. 후처리 파이프라인 (v3)
생성(512~768px) → 콘텐츠 bbox 크롭 → 채도컷 배경 제거(밝기>200 & 채도<0.16)
→ LANCZOS 다운스케일(타깃 정수비) → 알파 128 임계 정리 → **톤 하모나이즈(§2)**
→ 타깃 캔버스 정렬(바닥 기준선 = 캔버스 하단, 셀 중앙 피벗).

## 6. 배치 규칙 (레퍼런스 정합 — 운영자 "놓이는 위치 다름")
- 더미·광맥·가구: **셀 중앙 정렬**, 스프라이트가 셀 경계 안에 fit (1칸 오브젝트).
- 나무: 트렁크 밑동이 셀 중앙, 캐노피는 위 칸으로 overflow 허용.
- 벽: 연결 오토타일 (W1/W2) — 변형 세트 필수.

## 8. v3.1 톤 결정 채택 (2026-07-25 — art-tone-decisions 문서 기반)
1. **밸류 3계급**: 지형(-10% V) < 정적 오브젝트(V 0.20~0.85) < 캐릭터(V ≤0.92 유일 허용).
2. **계절 고정**: 늦여름~초가을. 적색 캐노피는 Maple 전용, Birch 는 황록.
3. **무광 통일**: 프롬프트 금지어 += `glossy, shiny, candy, plastic`. 유광 생성물 탈락.
4. **채도 3단**: 지형 S≤0.45 / 오브젝트 ≤0.65 / 캐릭터·포인트 ≤0.75(예외 0.85).
5. **아웃라인**: 인터랙티브만 은은한 다크 외곽선, 지형 금지.
- 하모나이즈 v2: 카테고리별 V/S 클램프 테이블 + Reinhard 통계 매칭 (기존 반입물
  소급: marble 명도 하향·granite 상향 수렴·birch 황록 시프트).
- 자가 스타일 LoRA: 확정본 30~50장 축적 시(가구·건물 물량전 직전) ai-toolkit 훈련.

## §9 v3.2 — 통일 문법 선언 (2026-07-24, 운영자 "근본적으로 뭐가 문제지" 진단 회신)

**진단**: 한 화면에 3개 시각 언어(구세대 픽셀+아웃라인 / 신세대 페인털리 무아웃라인
/ 절차 지형)가 공존하는 것이 "어우러지지 않음"의 근본 원인. 개별 에셋 품질 문제가
아님. 세대교체 중간 상태가 최악 구간이며, 처방은 문법 통일을 끝까지 완주하는 것.

**확정 문법 (모든 신규·재생성 에셋 의무)**:
1. **잉크 아웃라인** — 실루엣 + 잎뭉치/부위 경계 내부 라인워크 (FLUX 프롬프트에
   "bold dark ink outlines around the silhouette and around each clump, visible
   interior linework" 구워서 생성 — 후처리 라인 얹기보다 우수함이 확인됨)
2. **무광 페인털리** — §8 v3.1 채도·밸류 규정 유지
3. **드롭섀도 전원** — 나무=베이크(shadow_tree), 이동체=BlobShadow.Attach, 신규
   엔티티도 예외 없음 (화면 접착제)
4. **지형은 조용한 무대** — 절차 색필드+블레이드 댑(D2 확정), 원단 16조각 모듈로
   (반복 주기 4칸), 디테일은 데코 스캐터 담당
5. **밀도 통일** — 셀당 64px 기준, LANCZOS 다운스케일

**교체 순서 (남은 것)**: 나무 잉크판(진행 중) → 동물 4종 → 아이템·덤불 →
림(방향별 정적) → 구조물(벽 오토타일 포함). 프롬프트 템플릿은 trees_ink 배치의
BASE 문자열 재사용 (스크래치패드 art_v3/, 종료 전 스크립트화).
