## PawnSim — 어느 산골 마을의 하루하루

**주민에게 명령하지 않는다. 일감을 지정하면, 그들이 스스로 판단한다.**

조선 산골에 자리 잡은 여섯 명이 마을을 세우고 유지하는 시뮬레이션이다.
플레이어는 개별 주민의 행동을 직접 지정하지 않는다. 벌목·채굴 대상을 찍고 작업
우선순위와 하루 일정을 설정하면, 주민은 자신의 숙련도와 현재 상태(허기·피로·기분)에
따라 무엇을 언제 할지 스스로 정한다.

![아침의 마을. 주민 머리 위 라벨이 지금 각자 무엇을 하는지 보여준다 — 벌목, 연구, 운반. 플레이어가 이 중 어느 것도 직접 지시하지 않았다.](figures/01-morning.png)

**플레이**: https://melons.github.io/MelonS-Agents/play/
브라우저에서 링크를 열면 바로 실행된다. 설치나 계정이 필요 없다.

## 1. 목표

주민 여섯 명으로 마을을 세우고 유지한다. 소나무를 베고 돌을 캐 흙벽에 기와를 얹고,
논에 벼를 심어 먹고, 밤에는 이불을 덮고 자고, 며칠 뒤 찾아오는 약탈자를 견딘다.

화면 왼쪽 위에 **정착 목표** 네 가지가 상시 표시된다. 네 개를 모두 달성하면 승리다.

| # | 목표 | 달성 방법 |
|---|---|---|
| 1 | 목재 비축 | 나무를 우클릭해 벌목을 지정한다 |
| 2 | 지붕 아래 잠자리 | 벽으로 방을 하나 더 닫고 침대를 놓는다. 벽이 닫히면 지붕은 자동으로 생긴다 |
| 3 | 연구 1개 완료 | 작업 우선순위에서 연구를 올려 주민을 연구대에 붙인다 |
| 4 | 첫 습격 격퇴 | 습격을 막아내고 주민이 살아남는다 |

1번과 2번의 숫자는 시작할 때 이미 가진 것에서 얼마나 더 늘렸는지를 센다. 화면에
표시되는 숫자가 현재 목표치다.

- **승리** — 네 목표를 모두 달성하면 "정착 성공". 이후에도 마을은 계속 돌아가므로
  원하면 이어서 키워도 된다.
- **패배** — 주민이 전멸하면 게임 오버. 이후 관전 모드로 세계는 계속 돌아간다.

화면 위쪽의 `가치`는 점수가 아니다. 마을이 부유해질수록 습격이 강해지는데, 이
숫자가 그 기준이다.

## 2. 조작

마우스만으로 전부 조작할 수 있다. 브라우저에서는 게임 화면을 한 번 클릭해야
키보드 입력이 들어간다. 화면 아래 버튼만 써도 모든 기능을 쓸 수 있다.

| 하려는 것 | 조작 |
|---|---|
| 주민 선택 | 좌클릭. 또는 화면 위쪽 초상화 클릭 |
| 벌목·채광 지정 | 대상에 우클릭 |
| 건축 | 화면 아래 `건축` → 분류 → 항목 → 맵 클릭 |
| 배치 회전 | 건물을 놓기 전 `R` |
| 구역 지정 (저장·경작·지붕) | `건축` → `구역` → 드래그 |
| 작업 우선순위 | 화면 아래 `직업`. 좌클릭으로 0~4 변경 |
| 하루 일정 | 화면 아래 `일정` |
| 연구 | 화면 아래 `연구` |
| 시간 배속 | 오른쪽 아래 `멈춤 / 1x / 3x / 6x` |

![작업 우선순위 표. 가로가 직종, 세로가 주민이고 숫자 1이 가장 먼저다. 주민마다 잘하는 일이 달라 기본값도 서로 다르다.](figures/03-work-priority.png)

게임은 **일시정지 상태로 시작한다**. 배속 버튼을 눌러야 시간이 흐른다. 기본
배속은 3x다. 1x에서는 게임 속 하루가 실제 16.7분이라, 짧게 둘러보는 동안에는
하루가 지나가지 않는다.

## 3. 처음 5분에 확인할 것

게임의 주요 시스템을 순서대로 확인하는 방법이다.

**1. 게임을 시작하고 `3x`를 누른다.**
시작 캠프(집·밭·화덕·연구대)가 이미 있어서 아무 지시를 하지 않아도 수확·운반·요리가
돌아간다. 30초 안에 확인할 수 있다.

**2. 나무를 우클릭해 벌목을 지정한다.**
지정한 나무만 벤다. 여러 그루를 찍어 두면 주민들이 나눠서 처리한다.

**3. `건축` → `구조` → `목재 벽`을 몇 칸 배치한다.**
자재 운반과 건설이 자동으로 진행된다. 벽으로 방을 닫으면 지붕이 생긴다.

**4. `직업` 탭을 연다.**
여섯 명의 우선순위가 서로 다르다. 각자 잘하는 일에 1이 붙어 있다. 숫자를 바꾸면
마을 전체의 행동이 바뀐다.

**5. `6x`로 하루를 돌린다.**
시간대에 따라 화면 색이 바뀌고 주민들이 먹고 자고 일한다. 밤이 되면 등불을 켠다.

**6. 정착 목표를 확인한다.**
왼쪽 위 목표가 하나씩 초록색으로 바뀐다. 며칠 뒤 저녁에 약탈자가 온다.

![낮의 마을. 왼쪽 위에 자원과 정착 목표, 아래에 연구 진행이 함께 표시된다. 초록색으로 바뀐 항목이 달성한 목표다.](figures/02-midday.png)

## 4. 실행 방법

**플레이**: https://melons.github.io/MelonS-Agents/play/

- 권장 브라우저: Chrome, Edge
- 빌드 약 20MB. 첫 로딩에 시간이 걸릴 수 있다
- 소리는 브라우저 정책상 첫 클릭 이후 재생된다
- 오른쪽 아래 전체화면 버튼을 권장한다

**소스**: https://github.com/MelonS/MelonS-Agents
전체 소스와 커밋 기록이 공개돼 있다. 게임 코드는 `skills/game-prototype/`에 있다.

저장소를 클론해 직접 빌드할 경우, 외부 아트 팩은 재배포가 금지돼 포함하지 않았다.
팩이 없어도 게임이 그림을 직접 생성해 채우므로 그대로 빌드·실행된다. 팩을 쓰려면
`skills/game-prototype/scripts/extract-tinyswords.py`를 참조한다.

## 6. 현재 구현 범위

현재 버전은 프로토타입이다. 다음 기능은 아직 구현되지 않았다.

- 사회 상호작용은 잡담과 호감도까지만 있다. 관계망, 연애, 다툼은 없다.
- 지붕은 지정하면 주민이 지어야 완성된다. 자재는 들지 않지만 시간이 걸린다.
- 전투는 활과 근접 자동 공격 수준이다. 무기 장착 시스템은 미완성이다.
- 주민이 크게 무너지는 단계(멘탈 브레이크 상위 단계)는 설계만 하고 구현하지 않았다.
